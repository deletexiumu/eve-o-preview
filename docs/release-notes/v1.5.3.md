EVE-O Preview 1.5.3 fixes inline Markdown rendering in the Windows update dialog and refines silent background downloads and EVE-process-aware idle updates across macOS and Windows.

## Windows

- **Update dialog Markdown rendering:** release notes in the Windows update window now render **bold**, *italic*, ~~strikethrough~~, `inline code`, and clickable `https://` links instead of showing raw Markdown syntax. Numbered lists now show clean numbering without duplicate bullets.

## macOS and Windows

- **Silent background download:** once an update is detected (including via manual checks when automatic updates are enabled), the update package is downloaded and verified silently in the background while keeping Skip, Later, and Install Update available in the dialog. Clicking Install Update during a background download reuses the in-flight download instead of restarting it.
- **Process-aware idle installation:** after a background download completes, automatic installation never runs while any EVE Online process (`exefile.exe` / EVE client) is active—unless you explicitly click Install Update. Once all EVE processes have exited and the app is idle, the prepared update installs silently and relaunches automatically.

EVE-O Preview 1.5.3 修复了 Windows 更新弹窗的 Markdown 语法渲染问题，并完善了 macOS 与 Windows 的后台静默下载和按 EVE 进程状态择机更新逻辑。

### Windows

- **更新内容 Markdown 渲染：** Windows 更新弹窗现在正常渲染**粗体**、*斜体*、~~删除线~~、`行内代码`与可点击的 `https://` 链接，不再直接露出 `**` 等原始标记；有序列表不再重复显示圆点符号。

### macOS 与 Windows

- **后台静默下载：** 检测到新版本后（包括开启自动更新后的手动检查），更新包会在后台自动静默下载并完成校验，弹窗同时保留「跳过此版本」「稍后」与「安装更新」按钮。后台下载期间点击「安装更新」会直接衔接当前下载，不重复拉取。
- **检测 EVE 进程择机静默更新：** 后台下载完成后不会立即强行重启；只要检测到任何 EVE 进程正在运行，就不会自动安装，仅在你手动点击「安装更新」时才立即执行。待所有 EVE 进程退出且应用处于空闲状态后，再自动静默安装并重启。

EVE-O Preview 1.5.3 behebt die Markdown-Darstellung im Windows-Update-Dialog und verbessert den stillen Hintergrund-Download sowie die prozessbewusste Leerlauf-Installation auf macOS und Windows.

### Windows

- **Markdown-Darstellung in den Versionshinweisen:** Der Windows-Update-Dialog rendert **Fettschrift**, *Kursivschrift*, ~~Durchgestrichenes~~, `Inline-Code` und anklickbare `https://`-Links jetzt korrekt statt roher Markdown-Zeichen. Nummerierte Listen zeigen keine doppelten Aufzählungspunkte mehr.

### macOS und Windows

- **Stiller Hintergrund-Download:** Sobald ein Update erkannt wird (einschließlich manueller Prüfungen bei aktivierten automatischen Updates), wird das Paket still im Hintergrund heruntergeladen und geprüft, während „Überspringen“, „Später“ und „Update installieren“ verfügbar bleiben. Ein Klick auf „Update installieren“ übernimmt den laufenden Download, statt ihn neu zu starten.
- **Prozessbewusste Installation im Leerlauf:** Nach abgeschlossenem Download erfolgt kein sofortiger Neustart. Solange ein EVE-Online-Prozess läuft, wird niemals automatisch installiert – nur bei manuellem Klick auf „Update installieren“. Sobald alle EVE-Prozesse beendet sind und die App im Leerlauf ist, wird das Update still installiert und neu gestartet.

EVE-O Preview 1.5.3 corrige el renderizado de Markdown en el diálogo de actualización de Windows y perfecciona la descarga silenciosa en segundo plano y la instalación en inactividad según los procesos de EVE en macOS y Windows.

### Windows

- **Renderizado Markdown en las notas de actualización:** la ventana de actualización de Windows ahora muestra correctamente **negrita**, *cursiva*, ~~tachado~~, `código en línea` y enlaces `https://` clicables en lugar de los símbolos sin procesar. Las listas numeradas ya no muestran viñetas duplicadas.

### macOS y Windows

- **Descarga silenciosa en segundo plano:** en cuanto se detecta una nueva versión (también tras una comprobación manual con las actualizaciones automáticas activadas), el paquete se descarga y verifica silenciosamente en segundo plano mientras los botones Omitir, Más tarde e Instalar actualización siguen disponibles. Pulsar Instalar actualización reutiliza la descarga en curso sin reiniciarla.
- **Instalación en inactividad al detectar procesos de EVE:** al terminar la descarga no se fuerza el reinicio inmediato; mientras haya algún proceso de EVE Online en ejecución nunca se instala automáticamente, salvo que pulses Instalar actualización de forma manual. Cuando todos los procesos de EVE se cierren y la aplicación quede inactiva, la actualización se instala silenciosamente y se reinicia sola.

</details>
