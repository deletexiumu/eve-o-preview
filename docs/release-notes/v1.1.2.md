EVE-O Preview for macOS 1.1.2 adds a hotkey for hiding all thumbnails and tidies up the Clients page of Settings.

## New

- **Hotkey for "Hide all thumbnails":** on the Clients page, below the switch, you can now record one or more hotkeys: modifiers with a key, or modifiers with the middle or a side mouse button. Choose whether they work everywhere (Global) or only while an EVE client is in front (Only in EVE). The default is ⌃⌥⌘H (Control + Option + Command + H), Global. If "Show or hide all thumbnails" had no hotkey yet and ⌃⌥⌘H is not used by another action, the default is added once after upgrading; if you remove it, it stays removed.

## Fixed

- **Clients page:** the color, "Default" and "Show thumbnail" columns of the character list now line up regardless of the length of the character names. Very long names are shortened in the middle; hover to see the full name.

## Upgrading

From 1.1.0 or 1.1.1, the update installs from inside the app: automatically when no EVE client has been running for about a minute, when you quit, or from "Check for Updates…". From 1.0.0, download `EVE-O-Preview-1.1.2.dmg` and replace the app once. Screen Recording and Accessibility stay granted.

This build is signed with the project's own certificate and is not notarized. `SHA256SUMS.txt` lists the checksums of all files.

EVE-O Preview for macOS 1.1.2 добавляет сочетание клавиш для скрытия всех миниатюр и приводит в порядок страницу «Клиенты» в настройках.

### Новое

- **Сочетание клавиш для «Скрыть все миниатюры»:** на странице «Клиенты» под переключателем теперь можно записать одно или несколько сочетаний: модификаторы с клавишей или модификаторы со средней либо боковой кнопкой мыши. Выберите, где они действуют: везде («Везде») или только когда клиент EVE на переднем плане («Только в EVE»). По умолчанию — ⌃⌥⌘H (Control + Option + Command + H), везде. Если у действия «Показать или скрыть все миниатюры» ещё не было сочетания и ⌃⌥⌘H не занято другим действием, после обновления оно добавляется один раз; если удалить его, оно не вернётся.

### Исправлено

- **Страница «Клиенты»:** столбцы цвета, «По умолчанию» и «Показывать миниатюру» в списке персонажей теперь выровнены независимо от длины имён. Очень длинные имена сокращаются посередине; полное имя видно при наведении указателя.

### Обновление

С 1.1.0 или 1.1.1 обновление устанавливается из приложения: автоматически, когда клиент EVE не запущен около минуты, при выходе или через «Проверить наличие обновлений…». С 1.0.0 один раз скачайте `EVE-O-Preview-1.1.2.dmg` и замените приложение. Разрешения «Запись экрана» и «Универсальный доступ» сохраняются.

Эта сборка подписана собственным сертификатом проекта и не нотаризована. В `SHA256SUMS.txt` перечислены контрольные суммы всех файлов.

</details>
