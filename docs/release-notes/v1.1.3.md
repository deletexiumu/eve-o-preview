EVE-O Preview for macOS 1.1.3 adds French, German and Spanish to the interface languages.

## New

- **French, German and Spanish:** choose Français, Deutsch or Español on the General page of Settings; the change takes effect immediately. With "Follow System", the app now also picks these languages when one of them is the first supported language among your Mac's preferred languages. The update window shows the release notes in these languages from this version on. The translations are machine-generated; corrections are welcome.
- **README:** the project page is now also available in French, German and Spanish, and every language version links to the others.
