EVE-O Preview for macOS 1.3.0 gets automatic updates ready for two upcoming changes to the project's GitHub repository.

## Improved

- **Ready for the repository rename:** the repository will be renamed to `eve-o-preview` in a few weeks, because it will also host a native Windows version. From this version on, automatic updates accept downloads from both the current and the new repository address. Older versions can still see new releases after the rename, but they can't install them automatically, so please let this update install.
- **Ready for Windows releases in the same repository:** if GitHub ever lists a Windows release as the latest one, the update check now looks through the release list and picks the newest macOS release, instead of reporting an error.
- **Release notes for skipped versions:** the app now reads up to 100 releases when it shows the notes of versions you skipped, so Windows releases in the list don't push older macOS notes out.
