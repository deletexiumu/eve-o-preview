EVE-O Preview for macOS 1.1.0 adds in-app updates and one-click problem reports.

## New

- **Updates:** the app checks GitHub for new releases at launch and once a day, shows the release notes in your interface language, and installs an update after verifying the download's checksum and code signature. If anything fails, the installed app stays unchanged. Optionally, updates download in the background and install when you quit.
- **Report a Problem:** builds a diagnostics zip (environment summary, settings summary, app log and macOS crash reports) with your user name, computer name and character names redacted, lets you preview every file first, and opens a prefilled GitHub issue. Nothing is uploaded by the app.
- **Crash detection:** if EVE-O Preview quit unexpectedly, the next launch offers to report it.
- **Log files:** up to 5 MiB of logs in `~/Library/Logs/EVE-O Preview/`; "Verbose logging" in General records more detail.

## Network access

Version 1.0.0 made no network requests. From 1.1.0 the app connects to GitHub to check for and download updates. It sends only its version number, and no personal data. To stop automatic checks, clear "Check for updates automatically" in Settings > General > Updates.

## Upgrading from 1.0.0

1.0.0 has no updater: download `EVE-O-Preview-1.1.0.dmg` and replace the app in Applications once. Both versions are signed with the same certificate, so Screen Recording and Accessibility stay granted. Later versions can be installed from inside the app.

This build is signed with the project's own certificate and is not notarized. On a first install, open System Settings > Privacy & Security and click "Open Anyway". `SHA256SUMS.txt` lists the checksums of all files.

EVE-O Preview for macOS 1.1.0 新增应用内更新与一键报告问题。

### 新功能

- **更新：** 应用在启动时和每天检查一次 GitHub 上的新版本，按界面语言显示发布说明；安装前核对下载文件的校验和与代码签名，任何一步失败都保留原来的应用。可选在后台下载、退出时安装。
- **报告问题：** 生成诊断 zip（环境摘要、配置摘要、应用日志与 macOS 崩溃报告），其中的用户名、电脑名与角色名都已替换；生成前可预览每个文件，然后打开预填好的 GitHub Issue。应用本身不上传任何文件。
- **崩溃检测：** 应用意外退出后，下次启动时提示报告。
- **日志文件：** `~/Library/Logs/EVE-O Preview/` 下最多约 5 MiB；在「通用」页打开「详细日志」可记录更多信息。

### 联网

1.0.0 不联网。1.1.0 起应用会访问 GitHub 检查和下载更新，只发送版本号，不发送个人数据。要停止自动检查，在「设置 > 通用 > 更新」里关掉「自动检查更新」。

### 从 1.0.0 升级

1.0.0 没有更新功能：下载 `EVE-O-Preview-1.1.0.dmg`，手动替换一次「应用程序」里的应用。两个版本用同一张证书签名，屏幕录制与辅助功能权限会保留。以后的版本可以在应用内安装。

这个版本用本项目自己的证书签名，没有经过公证。首次安装时，到「系统设置 > 隐私与安全性」点「仍要打开」。`SHA256SUMS.txt` 列出全部文件的校验和。
