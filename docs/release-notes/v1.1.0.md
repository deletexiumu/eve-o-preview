EVE-O Preview for macOS 1.1.0 adds in-app updates and one-click problem reports.

## New

- **Updates:** the app checks GitHub for new releases at launch and once a day, shows the release notes in your interface language, and installs an update after verifying the download's checksum and code signature. If anything fails, the installed app stays unchanged. Optionally, updates download in the background and install when you quit.
- **Report a Problem:** builds a diagnostics zip (environment summary, settings summary, app log and macOS crash reports) with your user name, computer name and character names redacted, lets you preview every file first, and opens a prefilled GitHub issue. Nothing is uploaded by the app.
- **Crash detection:** if EVE-O Preview quit unexpectedly, the next launch offers to report it.
- **Log files:** up to 5 MiB of logs in `~/Library/Logs/EVE-O Preview/`; "Verbose logging" in General records more detail.

## Network access

Version 1.0.0 made no network requests. From 1.1.0 the app connects to GitHub to check for and download updates. It sends only its version number, and no personal data. To stop automatic checks, clear "Check for updates automatically" in Settings > General > Updates.

## Upgrading from 1.0.0

1.0.0 has no updater: download `EVE-O-Preview-1.1.0.dmg` and replace the app in Applications once. Both versions are signed with the same certificate, so Screen Recording and Accessibility stay granted. Later versions can be installed from inside the app.

This build is signed with the project's own certificate and is not notarized. On a first install, open System Settings > Privacy & Security and click "Open Anyway". `SHA256SUMS.txt` lists the checksums of all files.

<details><summary>한국어</summary>

EVE-O Preview for macOS 1.1.0에는 앱 내 업데이트와 원클릭 문제 신고 기능이 추가되었습니다.

### 새 기능

- **업데이트:** 앱이 실행할 때와 하루에 한 번 GitHub에서 새 릴리스를 확인하고, 릴리스 노트를 UI 언어로 보여 주며, 다운로드한 파일의 체크섬과 코드 서명을 검증한 뒤 업데이트를 설치합니다. 어느 단계에서든 실패하면 설치된 앱은 바뀌지 않습니다. 선택에 따라 업데이트를 백그라운드에서 다운로드하고 종료할 때 설치할 수 있습니다.
- **문제 신고:** 사용자 이름, 컴퓨터 이름, 캐릭터 이름을 가린 진단 zip(환경 요약, 설정 요약, 앱 로그, macOS 충돌 보고서)을 만들고, 먼저 모든 파일을 미리 볼 수 있게 한 다음, 미리 채워진 GitHub 이슈를 엽니다. 앱은 아무것도 업로드하지 않습니다.
- **충돌 감지:** EVE-O Preview가 예기치 않게 종료되었으면 다음 실행 때 신고할지 묻습니다.
- **로그 파일:** `~/Library/Logs/EVE-O Preview/`에 최대 5 MiB의 로그를 보관합니다. '일반'에서 '상세 로그'를 켜면 더 자세한 내용을 기록합니다.

### 네트워크 접근

1.0.0 버전은 네트워크 요청을 보내지 않았습니다. 1.1.0부터 앱은 업데이트를 확인하고 다운로드하기 위해 GitHub에 연결합니다. 버전 번호만 전송하며 개인 데이터는 전송하지 않습니다. 자동 확인을 중지하려면 설정 > 일반 > 업데이트에서 '자동으로 업데이트 확인'을 해제하십시오.

### 1.0.0에서 업그레이드

1.0.0에는 업데이트 기능이 없습니다. `EVE-O-Preview-1.1.0.dmg`를 다운로드하여 응용 프로그램 폴더의 앱을 한 번 교체하십시오. 두 버전은 같은 인증서로 서명되므로 화면 기록과 손쉬운 사용 권한이 유지됩니다. 이후 버전은 앱 안에서 설치할 수 있습니다.

이 빌드는 이 프로젝트 자체의 인증서로 서명되었으며 공증을 받지 않았습니다. 처음 설치할 때는 시스템 설정 > 개인정보 보호 및 보안을 열고 '그래도 열기'를 클릭하십시오. `SHA256SUMS.txt`에 모든 파일의 체크섬이 나와 있습니다.

<details><summary>Русский</summary>

EVE-O Preview for macOS 1.1.0 добавляет обновление из приложения и отчёты о проблемах в один щелчок.

### Новое

- **Обновления:** приложение проверяет новые выпуски на GitHub при запуске и раз в день, показывает примечания к выпуску на языке интерфейса и устанавливает обновление после проверки контрольной суммы и подписи кода загруженного файла. Если что-то не удалось, установленное приложение остаётся без изменений. По желанию обновления загружаются в фоне и устанавливаются при выходе из приложения.
- **Сообщить о проблеме:** приложение собирает zip-архив с диагностикой (сводка об окружении, сводка настроек, журнал приложения и отчёты о сбоях macOS), в котором имя пользователя, имя компьютера и имена персонажей заменены, позволяет сначала просмотреть каждый файл и открывает заранее заполненный issue на GitHub. Само приложение ничего не выгружает.
- **Обнаружение сбоев:** если EVE-O Preview неожиданно завершилась, при следующем запуске приложение предлагает сообщить об этом.
- **Файлы журнала:** до 5 МиБ журналов в `~/Library/Logs/EVE-O Preview/`; параметр «Подробный журнал» на странице «Общие» записывает больше подробностей.

### Доступ к сети

Версия 1.0.0 не выполняла сетевых запросов. Начиная с 1.1.0 приложение подключается к GitHub для проверки и загрузки обновлений. Оно отправляет только номер своей версии и никаких личных данных. Чтобы отключить автоматическую проверку, снимите флажок «Автоматически проверять наличие обновлений» в разделе «Настройки» > «Общие» > «Обновления».

### Обновление с 1.0.0

В 1.0.0 нет механизма обновления: один раз скачайте `EVE-O-Preview-1.1.0.dmg` и замените приложение в папке «Программы». Обе версии подписаны одним и тем же сертификатом, поэтому разрешения «Запись экрана» и «Универсальный доступ» сохраняются. Более поздние версии можно устанавливать прямо из приложения.

Эта сборка подписана собственным сертификатом проекта и не нотаризована. При первой установке откройте «Системные настройки» > «Конфиденциальность и безопасность» и нажмите «Все равно открыть». В `SHA256SUMS.txt` перечислены контрольные суммы всех файлов.

</details>
