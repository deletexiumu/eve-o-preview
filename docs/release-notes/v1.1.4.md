EVE-O Preview for macOS 1.1.4 shows the notes of every version you skipped in the update window.

## New

- **Notes for skipped versions:** when you update across several versions (for example from 1.1.4 to 1.1.6), the update window now lists the notes of each newer version, newest first, each under its own "Version …" heading, in your interface language. To do this, the app requests the release list from GitHub once when it offers a new version. If that request fails, the window shows only the latest version's notes, and the update works as before.
