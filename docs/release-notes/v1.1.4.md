EVE-O Preview for macOS 1.1.4 shows the notes of every version you skipped in the update window.

## New

- **Notes for skipped versions:** when you update across several versions (for example from 1.1.4 to 1.1.6), the update window now lists the notes of each newer version, newest first, each under its own "Version …" heading, in your interface language. To do this, the app requests the release list from GitHub once when it offers a new version. If that request fails, the window shows only the latest version's notes, and the update works as before.

## Upgrading

Versions up to 1.1.3 do not have this feature yet, so this update only shows the notes for 1.1.4. For what changed in 1.1.2 and 1.1.3, see the release page.

From 1.1.0 or later, the update installs from inside the app: automatically when no EVE client has been running for about a minute, when you quit, or from "Check for Updates…". From 1.0.0, download `EVE-O-Preview-1.1.4.dmg` and replace the app once. Screen Recording and Accessibility stay granted.

This build is signed with the project's own certificate and is not notarized. `SHA256SUMS.txt` lists the checksums of all files.
