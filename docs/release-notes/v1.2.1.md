EVE-O Preview for macOS 1.2.1 makes it obvious which character you are playing, and makes thumbnails and overlays easier to resize.

## New

- **Highlight on the active character:** the thumbnail of the EVE window you are using now gets a highlighted border (yellow-green by default). "Highlight active client" on the Previews & Layout page is now on by default, and this update turns it on once for existing settings. You can change the color and thickness there, set a color per character on the Clients page, or turn it off again; it will not be turned back on.
- **Resize by dragging an edge:** move the pointer to the edge or corner of a character thumbnail, the intel overlay or the translation overlay, and drag with the left button to resize it. The pointer changes to a resize arrow over the edge. A plain click on a thumbnail edge still switches to that character, and the overlay's scroll bar can still be dragged. Right-drag and Option-drag work as before.
- **Overlay position and size in Settings:** the Overlay group on the Intel and Translation pages now has X, Y, width and height fields. Type a value and press Return to move or resize the overlay. Sizes are limited to 220×120 through 900×900, and an off-screen position is pulled back.

## Upgrading

From 1.1.0 or later, the update installs from inside the app: automatically when no EVE client has been running for about a minute, when you quit, or from "Check for Updates…". From 1.0.0, download `EVE-O-Preview-1.2.1.dmg` and replace the app once. Screen Recording and Accessibility stay granted.

This build is signed with the project's own certificate and is not notarized. `SHA256SUMS.txt` lists the checksums of all files.
