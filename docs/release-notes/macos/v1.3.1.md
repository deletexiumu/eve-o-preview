EVE-O Preview for macOS 1.3.1 changes nothing in the app. It is the first version built from the project's new folder layout.

The project's source files are now split into a folder for the macOS version, a folder for the upcoming native Windows version, and a folder for the data both versions share. This version checks that building, signing and automatic updates still work after the move. Your settings and permissions stay as they are.
