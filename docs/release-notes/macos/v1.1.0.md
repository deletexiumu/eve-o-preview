EVE-O Preview for macOS 1.1.0 adds in-app updates and one-click problem reports.

## New

- **Updates:** the app checks GitHub for new releases at launch and once a day, shows the release notes in your interface language, and installs an update after verifying the download's checksum and code signature. If anything fails, the installed app stays unchanged. By default, updates download in the background and install with a restart once no EVE client has been running for about a minute, or when you quit; this can be turned off in Settings > General > Updates.
- **Report a Problem:** builds a diagnostics zip (environment summary, settings summary, app log and macOS crash reports) with your user name, computer name and character names redacted, lets you preview every file first, and opens a prefilled GitHub issue. Nothing is uploaded by the app.
- **Crash detection:** if EVE-O Preview quit unexpectedly, the next launch offers to report it.
- **Dock icon:** EVE-O Preview now also shows an icon in the Dock; clicking it opens Settings. To keep only the menu bar icon, clear "Show icon in Dock" in Settings > General.
- **Log files:** up to 5 MiB of logs in `~/Library/Logs/EVE-O Preview/`; "Verbose logging" in General records more detail.

## Network access

From 1.1.0 the app connects to GitHub to check for and download updates. It sends only its version number, and no personal data. To stop automatic checks, clear "Check for updates automatically" in Settings > General > Updates.

EVE-O Preview for macOS 1.1.0 新增应用内更新与一键报告问题。

### 新功能

- **更新：** 应用在启动时和每天检查一次 GitHub 上的新版本，按界面语言显示发布说明；安装前核对下载文件的校验和与代码签名，任何一步失败都保留原来的应用。默认在后台下载，没有 EVE 客户端运行满约 1 分钟时安装并重新启动，或在退出时安装；可在「设置 > 通用 > 更新」里关掉。

EVE-O Preview for macOS 1.1.0 では、アプリ内でのアップデートと、ワンクリックでの問題の報告が追加されました。

### 新機能

- **アップデート：** アプリは起動時と 1 日に 1 回、GitHub で新しいリリースを確認し、インターフェイスの言語でリリースノートを表示します。ダウンロードしたファイルのチェックサムとコード署名を検証してから、アップデートをインストールします。いずれかの手順が失敗した場合、インストール済みのアプリは変更されません。初期設定では、アップデートをバックグラウンドでダウンロードし、EVE クライアントが約 1 分間起動していなければ再起動してインストールします。終了時にもインストールします。「設定」>「一般」>「アップデート」でオフにできます。
- **問題を報告：** 診断用の zip（環境の概要、設定の概要、アプリのログ、macOS のクラッシュレポート）を作成します。ユーザー名、コンピュータ名、キャラクター名は伏せられます。事前にすべてのファイルをプレビューでき、内容を記入済みの GitHub の Issue を開きます。アプリが何かをアップロードすることはありません。
- **クラッシュの検出：** EVE-O Preview が予期せず終了した場合、次回の起動時に報告するかどうかを尋ねます。
- **Dock アイコン：** Dock にもアイコンを表示し、クリックすると設定が開きます。メニューバーのアイコンだけにするには、「設定」>「一般」で「Dock にアイコンを表示」をオフにします。
- **ログファイル：** `~/Library/Logs/EVE-O Preview/` に最大 5 MiB のログを保存します。「一般」ページで「詳細ログ」をオンにすると、より詳しい情報を記録します。

### ネットワークアクセス

1.1.0 以降、アプリはアップデートの確認とダウンロードのために GitHub に接続します。送信するのはバージョン番号だけで、個人データは送信しません。自動確認を止めるには、「設定」>「一般」>「アップデート」で「アップデートを自動的に確認」のチェックを外します。

</details>

<details><summary>한국어</summary>

EVE-O Preview for macOS 1.1.0에는 앱 내 업데이트와 원클릭 문제 신고 기능이 추가되었습니다.

### 새 기능

- **업데이트:** 앱이 실행할 때와 하루에 한 번 GitHub에서 새 릴리스를 확인하고, 릴리스 노트를 UI 언어로 보여 주며, 다운로드한 파일의 체크섬과 코드 서명을 검증한 뒤 업데이트를 설치합니다. 어느 단계에서든 실패하면 설치된 앱은 바뀌지 않습니다. 기본적으로 업데이트를 백그라운드에서 다운로드하고, EVE 클라이언트가 약 1분 동안 실행되지 않으면 다시 실행하며 설치하거나 종료할 때 설치합니다. 설정 > 일반 > 업데이트에서 끌 수 있습니다.
- **문제 신고:** 사용자 이름, 컴퓨터 이름, 캐릭터 이름을 가린 진단 zip(환경 요약, 설정 요약, 앱 로그, macOS 충돌 보고서)을 만들고, 먼저 모든 파일을 미리 볼 수 있게 한 다음, 미리 채워진 GitHub 이슈를 엽니다. 앱은 아무것도 업로드하지 않습니다.
- **충돌 감지:** EVE-O Preview가 예기치 않게 종료되었으면 다음 실행 때 신고할지 묻습니다.
- **Dock 아이콘:** Dock에도 아이콘을 표시하며, 클릭하면 설정이 열립니다. 메뉴 막대 아이콘만 남기려면 설정 > 일반에서 "Dock에 아이콘 표시"를 끄십시오.
- **로그 파일:** `~/Library/Logs/EVE-O Preview/`에 최대 5 MiB의 로그를 보관합니다. '일반'에서 '상세 로그'를 켜면 더 자세한 내용을 기록합니다.

### 네트워크 접근

1.1.0부터 앱은 업데이트를 확인하고 다운로드하기 위해 GitHub에 연결합니다. 버전 번호만 전송하며 개인 데이터는 전송하지 않습니다. 자동 확인을 중지하려면 설정 > 일반 > 업데이트에서 '자동으로 업데이트 확인'을 해제하십시오.

<details><summary>Русский</summary>

EVE-O Preview for macOS 1.1.0 добавляет обновление из приложения и отчёты о проблемах в один щелчок.

### Новое

- **Обновления:** приложение проверяет новые выпуски на GitHub при запуске и раз в день, показывает примечания к выпуску на языке интерфейса и устанавливает обновление после проверки контрольной суммы и подписи кода загруженного файла. Если что-то не удалось, установленное приложение остаётся без изменений. По умолчанию обновления загружаются в фоне и устанавливаются с перезапуском, когда клиент EVE не запущен около минуты, либо при выходе из приложения; это можно выключить в разделе «Настройки» > «Общие» > «Обновления».
- **Сообщить о проблеме:** приложение собирает zip-архив с диагностикой (сводка об окружении, сводка настроек, журнал приложения и отчёты о сбоях macOS), в котором имя пользователя, имя компьютера и имена персонажей заменены, позволяет сначала просмотреть каждый файл и открывает заранее заполненный issue на GitHub. Само приложение ничего не выгружает.
- **Обнаружение сбоев:** если EVE-O Preview неожиданно завершилась, при следующем запуске приложение предлагает сообщить об этом.
- **Значок в Dock:** EVE-O Preview теперь показывает значок и в Dock; щелчок по нему открывает настройки. Чтобы оставить только значок в строке меню, снимите флажок «Показывать значок в Dock» в разделе «Настройки» > «Общие».
- **Файлы журнала:** до 5 МиБ журналов в `~/Library/Logs/EVE-O Preview/`; параметр «Подробный журнал» на странице «Общие» записывает больше подробностей.

### Доступ к сети

Начиная с 1.1.0 приложение подключается к GitHub для проверки и загрузки обновлений. Оно отправляет только номер своей версии и никаких личных данных. Чтобы отключить автоматическую проверку, снимите флажок «Автоматически проверять наличие обновлений» в разделе «Настройки» > «Общие» > «Обновления».

</details>
