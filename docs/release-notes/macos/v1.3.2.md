EVE-O Preview for macOS 1.3.2 moves to the project's new GitHub address.

## Improved

- **New repository address:** the project's GitHub repository is now named `eve-o-preview`, because it will also host a native Windows version. Update checks, release links and "Report a Problem…" now use https://github.com/deletexiumu/eve-o-preview. The old address still redirects there, and links saved by earlier versions keep working.
