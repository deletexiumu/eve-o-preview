First release of EVE-O Preview for macOS: a native Swift / AppKit / ScreenCaptureKit re-implementation of the preview and switching features of [EveOPlus/eve-o-preview](https://github.com/EveOPlus/eve-o-preview), for macOS 14 and later (universal binary, Apple Silicon and Intel).

## Highlights

- A live thumbnail for every EVE client; click or press a hotkey to switch.
- Cycle groups, per-character hotkeys, and middle/side mouse button hotkeys that can be global or EVE-only.
- Snapping layout saved per character, zoom on hover, visibility rules, and profiles.
- Optional combat alerts: a thumbnail flashes when its character is attacked (reads the game logs only).
- UI in English, Chinese, Russian, Japanese and Korean.

## Install

1. Download `EVE-O-Preview-1.0.0.dmg` and drag the app into Applications.
2. This build is signed with the project's own self-signed certificate and is not notarized. On first launch, open System Settings > Privacy & Security and click "Open Anyway", or run `xattr -dr com.apple.quarantine "/Applications/EVE-O Preview.app"`.
3. Grant Screen Recording and Accessibility when the app asks. Every release is signed with the same certificate, so the permissions are kept when you upgrade.

`SHA256SUMS.txt` lists the checksums of the dmg and the source archives. See the [README](https://github.com/deletexiumu/eve-o-preview-macos#readme) for details.

<details><summary>Русский</summary>

Первый выпуск EVE-O Preview for macOS: нативная реализация на Swift / AppKit / ScreenCaptureKit функций предпросмотра и переключения из [EveOPlus/eve-o-preview](https://github.com/EveOPlus/eve-o-preview) для macOS 14 и новее (универсальный двоичный файл для Apple Silicon и Intel).

### Основные возможности

- Живая миниатюра для каждого клиента EVE; переключение щелчком или горячей клавишей.
- Группы циклического переключения, горячие клавиши для отдельных персонажей и горячие клавиши на средней и боковых кнопках мыши, работающие везде или только в EVE.
- Раскладка с привязкой, сохраняемая для каждого персонажа, увеличение при наведении, правила видимости и профили.
- Необязательные боевые оповещения: миниатюра мигает, когда персонажа атакуют (приложение только читает игровые журналы).
- Интерфейс на английском, китайском, русском, японском и корейском языках.

### Установка

1. Скачайте `EVE-O-Preview-1.0.0.dmg` и перетащите приложение в папку «Программы».
2. Эта сборка подписана собственным самоподписанным сертификатом проекта и не нотаризована. При первом запуске откройте «Системные настройки» > «Конфиденциальность и безопасность» и нажмите «Все равно открыть» или выполните `xattr -dr com.apple.quarantine "/Applications/EVE-O Preview.app"`.
3. Когда приложение попросит, разрешите запись экрана и универсальный доступ. Все релизы подписаны одним и тем же сертификатом, поэтому при обновлении разрешения сохраняются.

В `SHA256SUMS.txt` перечислены контрольные суммы dmg и архивов исходного кода. Подробности — в [README на русском](https://github.com/deletexiumu/eve-o-preview-macos/blob/main/README.ru.md).
