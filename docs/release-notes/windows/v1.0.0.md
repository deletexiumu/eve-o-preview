EVE-O Preview for Windows 1.0.0 is the first stable version of the native Windows app. It is a portable zip for 64-bit Windows 10 22H2 and Windows 11.

## New

- **Live thumbnails:** EVE clients are found automatically, including after login renames, and shown as live DWM thumbnails with titles, borders and a highlight for the active client.
- **Switching:** click a thumbnail to switch, Ctrl+click to minimize. Cycle groups, per-character hotkeys, and hotkeys for hiding or minimizing everything. Mouse middle and side buttons can be used as hotkeys.
- **Layout:** drag to move and resize, snapping, locked layout, per-character positions, hover zoom and opacity. Visibility rules and multiple profiles.
- **Alerts and overlays:** combat alerts from the game logs, the intel overlay (character lookup and jump counts) and the chat translation overlay. API keys are stored in Windows Credential Manager.
- **Settings:** a Windows 11 style Settings window with light and dark themes, 8 interface languages, and an Environment page that checks the log folders and how the clients are running.
- **Updates:** checks GitHub once a day. Each update is verified with a signature and a checksum before it is installed. By default updates download in the background and install when no EVE client has been running for a minute, or when you quit. If a new version fails to start, the previous one is restored.
- **Diagnostics:** log files, detection of unexpected exits, and "Report a Problem…" with a prefilled GitHub issue.
- **Start with Windows:** an option under General.

## Known limitations

- The exe is not code-signed yet, so Windows SmartScreen may warn the first time you run it. Choose "More info", then "Run anyway".
- Keep the folder somewhere you can write to (not "Program Files"), so updates can replace the exe.
- Settings are not imported from the original EVE-O Preview for Windows.
