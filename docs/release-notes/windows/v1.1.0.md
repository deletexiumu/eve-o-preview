EVE-O Preview for Windows 1.1.0 can limit the frame rate of your EVE clients through the graphics driver.

## New

- **Game frame rate:** a new "Game frame rate" group on the General page caps every EVE client at the same frame rate (60 by default). While multiboxing, this makes switching between clients much smoother and saves GPU power. It is off until you turn it on.
- It only changes the graphics driver's own setting and never touches the game clients. With NVIDIA it sets "Max Frame Rate" for exefile.exe; with Intel it sets a frame rate limit for exefile.exe; with AMD it turns on Frame Rate Target Control, which the AMD driver can only apply to every game on the PC. Turning it off restores the previous setting.
- Clients that are already running pick it up after a restart. It is a driver setting, so it stays in effect even when EVE-O Preview isn't running.

## Known limitations

- AMD and Intel support hasn't been tested on real hardware yet. If it doesn't work, please report the message or error code shown under the switch.
