<!-- lang:en -->
EVE-O Preview 1.5.2 adds an animated visual effect when Lock Layout is enabled, layered cleanly inside the active client highlight border without replacing it.

## macOS and Windows

- **Lock Layout visual animation:** enabling Lock Layout plays a snap-in corner clamp and diagonal light sheen across thumbnails, followed by gently breathing tactical corner brackets and a flowing inner perimeter glint. The entire lock overlay is drawn strictly inside the active highlight or neutral border, so the active window highlight and layout lock effect stack together cleanly. Info overlays and the Windows settings preview also reflect the locked state, and reduced-motion system settings automatically switch the effect to a static indicator.

- **锁定布局视觉特效动画：** 开启「锁定布局」时，缩略图会播放四角锁扣向四角卡紧锁定与对角流光扫过的开启特效，随后保持柔和呼吸的青蓝角标与沿内圈巡游的流光动画。整个锁定特效严格绘制在活动高亮边框（或中性边框）之内侧，不覆盖原有的活动窗口高亮，两种效果清晰叠加。预警与翻译浮窗以及 Windows 设置页的预览区也会同步呈现锁定视觉；当系统开启减弱动态效果或关闭动画效果时，自动切换为静态角标显示。
