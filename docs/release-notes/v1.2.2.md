EVE-O Preview for macOS 1.2.2 tells you when the translation overlay is empty because EVE is not writing a chat log.

## Improved

- **Translation overlay explains missing chat logs:** the overlay can only translate what EVE writes to its chat log files. When EVE has written no log in the last 48 hours for any of the translation channels on the active character, the overlay now says so on its status line, instead of only showing "No messages yet". The line disappears by itself once EVE creates the log file.
- **Local, Corp and Alliance with a non-English EVE client:** the EVE client for Mac writes no chat log for these channels while its language is Chinese, and possibly other non-English languages, so neither overlay could see their messages. When these channels are the ones missing, the status line now says to set EVE's language to English. After switching, log the character in again.
