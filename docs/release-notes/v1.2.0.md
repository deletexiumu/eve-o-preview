EVE-O Preview for macOS 1.2.0 adds an intel overlay and a chat translation overlay.

## New

- **Intel overlay:** choose your intel channels on the new Intel page. The overlay reads their chat logs and shows, for each report, the systems with their jump distance from the active client's system, the ships, and the number of hostiles. Your location comes from game-log jump and undock lines and the Local chat log, or you can set it by hand or pick a reference system.
- **Pilot names checked online:** when several English words run together in a report, the app asks CCP's ESI which of them are real character names, so "two pilots" and "one pilot with a three-word name" are counted correctly. A name that stands alone as one word is never looked up. You can turn this off on the Intel page.
- **Chat translation overlay:** choose channels on the new Translation page, pick a target language and a model service (DeepSeek, Claude, OpenAI, Qwen, Kimi, Ollama, or any OpenAI-compatible address). System and ship names are fixed to their official names before the text goes to the model. The API key is stored only in the macOS Keychain.
- **Both overlays** show only the active EVE window's character, keep the newest message at the bottom and stay scrolled there unless you scroll up. Background opacity and font size are adjustable; move them with a right-drag or Option-drag, and resize from the edges.

Both features are off until you turn them on. The map and ship names come from CCP's static data and ship inside the app.

## Upgrading

From 1.1.0 or later, the update installs from inside the app: automatically when no EVE client has been running for about a minute, when you quit, or from "Check for Updates…". From 1.0.0, download `EVE-O-Preview-1.2.0.dmg` and replace the app once. Screen Recording and Accessibility stay granted.

This build is signed with the project's own certificate and is not notarized. `SHA256SUMS.txt` lists the checksums of all files.
