<!-- lang:en -->
EVE-O Preview 1.4.0 is the first version released for macOS and Windows together. From now on both apps share the same version number, so the Windows app goes straight from 1.1.0 to 1.4.0.

## macOS and Windows

- **Make all thumbnails the same size:** on the Previews & Layout page this is now two buttons. "Match active client" gives every thumbnail the size of the active (highlighted) client's thumbnail; the text under it names that character, and the button is greyed out when no character's client is active. "Use default size" sets every thumbnail back to the default size, as before. Both only change the size, never the position.

## Windows

- Fixed: on the Switching & Hotkeys page, recording a key combination such as Ctrl+Shift+J often failed.

- 修正：「切り替えとホットキー」ページで Ctrl+Shift+J のようなキーの組み合わせを登録すると、うまく記録されないことがよくありました。
