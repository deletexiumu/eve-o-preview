EVE-O Preview 1.5.0 changes how both apps look for updates.

## macOS and Windows

- **Update prompts per platform:** each app is now offered only versions that change it. A release that only fixes the other platform no longer shows an update prompt, and when you skip several versions, the "What's new" text lists only the versions and sections for your platform.
- **Faster update downloads worldwide:** the update information and installers now come from a CDN (Cloudflare), with GitHub as the fallback. Every file is checked against a signed list before it is used, so the download source does not need to be trusted.
- Versions 1.4.1 and earlier still check the old way, so they may be offered this version once even though it is needed on both platforms anyway.
