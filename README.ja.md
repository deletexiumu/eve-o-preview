# EVE-O Preview for macOS & Windows

[English](README.md) | [简体中文](README.zh-CN.md) | **日本語** | [한국어](README.ko.md) | [Русский](README.ru.md) | [Français](README.fr.md) | [Deutsch](README.de.md) | [Español](README.es.md)

この日本語訳は機械翻訳で作成したもので、英語版と内容が異なる場合は[英語版の README](README.md) が優先されます。

EVE-O Preview は、実行中のすべての EVE Online クライアントのライブサムネイルを表示します。サムネイルをクリックするか、グローバルホットキーを押すと、そのクライアントに切り替わります。

このリポジトリには 2 つのネイティブアプリがあります。macOS 版は Swift、Windows 版は Rust で書かれています。設定ファイルの形式、UI の文言、テストケースは `shared/` で共有し、それぞれのプラットフォームの API を使います。

どちらも [EveOPlus/eve-o-preview](https://github.com/EveOPlus/eve-o-preview)（Windows、GPL-3.0）の機能を再実装したものです。上流の C# コードを移植したものではなく、UI と設定ファイルの形式も上流とは異なります。

## Windows

EVE-O Preview for Windows 1.0 は 2026-11-24 にリリースされました。機能は macOS 版と同じです：DWM のライブサムネイル、切り替えとホットキー（マウスボタンを含む）、レイアウト、表示ルール、戦闘アラート、偵察オーバーレイとチャット翻訳オーバーレイ、プロファイル、署名を確認するアップデート、問題の報告。macOS 版との違い：

- **ゲームのフレームレート**（1.1 から、既定はオフ）：「一般」ページの「ゲームのフレームレート」グループで、グラフィックスドライバーを通じてすべての EVE クライアントを同じフレームレート（既定は 60）に制限します。マルチボックス時のクライアントの切り替えがスムーズになります。ゲームクライアントには触れません。NVIDIA では exefile.exe の「最大フレームレート」を、Intel では exefile.exe のフレームレート上限を設定します。AMD ドライバーはこの PC のすべてのゲームをまとめてしか制限できません。オフにすると元のドライバー設定に戻します。AMD と Intel への対応はまだ実機で検証されていません。
- 「一般」ページの **Windows へのサインイン時に起動**。
- メニューバーアイコンの代わりに通知領域のアイコン：左クリックで設定、右クリックでメニューを開きます。
- API キーは macOS のキーチェーンの代わりに Windows 資格情報マネージャーに保存します。

### Windows へのインストール

64 ビット版の Windows 10 22H2 または Windows 11 が必要です。

1. [Releases](https://github.com/deletexiumu/eve-o-preview/releases) ページから `EVE-O-Preview-<バージョン>-windows-x64.zip` をダウンロードします。1.4.0 以降は macOS 版と Windows 版が同じリリース（タグ `v<バージョン>`）で公開されます。それ以前の Windows 版のタグは `win-v<バージョン>` です。
2. 書き込みできる場所（「ドキュメント」や `D:\Games` など）にフォルダを展開します。「Program Files」は避けてください。アップデートは exe をその場で置き換えます。
3. `EVE-O Preview.exe` を実行します。exe にはまだコード署名がないため、初回は Windows SmartScreen の警告が出ることがあります。「詳細情報」を選び、「実行」を選んでください。

設定は `%APPDATA%\EVE-O Preview\config.json`、ログは `%LOCALAPPDATA%\EVE-O Preview\logs\` に保存されます。元の EVE-O Preview の設定は取り込みません。アンインストールするには、トレイのメニューから終了し、「Windows へのサインイン時に起動」をオンにしていた場合はオフにしてから、アプリのフォルダと上の 2 つのフォルダを削除します。ソースからのビルドは [windows/README.md](windows/README.md) を参照してください。

以下は macOS 版の説明です。

## 機能

- クライアントの検出：クライアントの起動、終了、ログイン後の名前の変更に合わせて、サムネイルが自動的に更新されます。
- ライブサムネイル：クライアントごとに ScreenCaptureKit のストリームを 1 本使います。サイズとフレームレートは調整できます。
- サムネイルパネル：フォーカスを奪わず、すべての操作スペースに表示され、オプションで常に手前に表示できます。デフォルトでは 2 ポイントの薄いグレーの枠線が付くため、隣り合うサムネイルを見分けやすくなっています。色と太さは調整でき、枠線をオフにすることもできます。
- 切り替え：サムネイルを左クリックするとそのクライアントに切り替わり、Ctrl+クリックで最小化します。右クリックメニューには「最小化」「すべて最小化」「サイクルでスキップ」「このサムネイルを隠す」「デフォルトのサイズに戻す」があります。
- オーバーレイ：キャラクター名のタイトル、アクティブなクライアントのハイライト枠線（色はキャラクターごとに設定可能。表示中は薄いグレーの枠線の代わりに表示されます）、サイクルでスキップ中であることを示すマーク。
- ホバー時に拡大（基準点 9 か所）と不透明度。
- 表示：アクティブなクライアントのサムネイルを隠す、EVE が前面にないときに隠す（遅延あり）、キャラクターごとに隠す、すべて隠す。
- レイアウト：ドラッグで移動とサイズ変更ができ、ほかのサムネイルや画面の端にスナップします。レイアウトのロックも可能です。位置とサイズはキャラクターごとに保存されます。ログイン画面のクライアントは別の初期位置を使います。
- サイクルグループ：進むホットキーと戻るホットキー、現在のセッション中のスキップ、キャラクターごとのホットキー、ログイン画面のクライアントを順に切り替えるホットキー、すべて隠すホットキーとすべて最小化するホットキー。ホットキーにはマウスの中ボタンとサイドボタンを使え、ホットキーごとにグローバルか EVE 内のみかを選べます。
- 戦闘アラート（デフォルトはオフ）：ゲームログを読み取り、キャラクターが攻撃されるとそのキャラクターのサムネイルを点滅させます。
- 偵察オーバーレイ（デフォルトはオフ）：指定した偵察チャンネルのチャットログを読み取り、前面の EVE ウインドウのキャラクターについて、敵がどの星系で報告されたか、何ジャンプ先か、何人いるか、どの艦船かを表示します（[偵察オーバーレイ](#偵察オーバーレイ)を参照）。
- チャット翻訳オーバーレイ（デフォルトはオフ）：指定したチャンネルにある他言語のメッセージを、選んだモデルサービスとご自身の API キーで、あなたの言語に翻訳します（[チャット翻訳](#チャット翻訳)を参照）。
- プロファイル：作成、複製、名前の変更、削除、切り替え。
- アップデート：GitHub で新しいリリースを確認し、ダウンロードしたファイルとそのコード署名を検証してから、アプリ内でインストールします（[アップデート](#アップデート)を参照）。
- 問題の報告：個人情報を伏せた診断用の zip を作成し、内容を記入済みの GitHub の Issue を開きます。アプリが予期せず終了した場合は、次回の起動時に報告するかどうかを尋ねます（[問題を報告](#問題を報告)を参照）。
- Windows のトレイアイコンの代わりにメニューバーアイコンを使います。
- 10 ページの設定ウインドウ：「クライアント」「プレビューとレイアウト」「切り替えとホットキー」「アラート」「偵察」「翻訳」「プロファイル」「一般」「権限」「情報」。
- UI の言語：英語（デフォルト）、中国語、ロシア語、日本語、韓国語、フランス語、ドイツ語、スペイン語。「一般」ページで切り替えるか、「システムに合わせる」を選びます。変更はすぐに反映されます。ロシア語、日本語、韓国語、フランス語、ドイツ語、スペイン語の翻訳は機械翻訳です。修正を歓迎します。

## 動作環境

- macOS 14 以降（Apple Silicon または Intel）。リリース版の dmg にはユニバーサルバイナリが含まれています。
- EVE クライアントはウインドウモードでの実行をお勧めします。1.1.1 以降はネイティブのフルスクリーンのクライアントにも対応しています（「サムネイルを常に手前に表示」がオンのとき、サムネイルはフルスクリーンの画面の上に表示されます）が、各クライアントは専用の操作スペースにあるため、切り替えると操作スペースの切り替えアニメーションが再生されます。

## インストール

### リリース版をダウンロード

1. [Releases](https://github.com/deletexiumu/eve-o-preview/releases) ページから `EVE-O-Preview-<version>.dmg` をダウンロードします。
2. dmg を開き、`EVE-O Preview.app` を「アプリケーション」フォルダにドラッグします。
3. アプリを開きます。メニューバーにアイコンが表示され、初回起動時には設定ウインドウが「権限」ページで開きます。

プロジェクトに Apple Developer ID がないため、リリースビルドはこのプロジェクト独自の自己署名証明書で署名されており、公証も受けていません。初回起動時、macOS は開発元を検証できないというメッセージを表示してアプリをブロックします。アプリを開くには、次の手順を実行します。

1. 「システム設定」>「プライバシーとセキュリティ」を開きます。
2. 下にスクロールして EVE-O Preview に関するメッセージを探し、「このまま開く」をクリックしてから確認します。

macOS に「壊れているため開けません」と表示された場合、または上記の手順の代わりに、ターミナルで隔離属性を削除します。

```sh
xattr -dr com.apple.quarantine "/Applications/EVE-O Preview.app"
```

**注意：** すべてのリリースは同じ証明書で署名されているため、アップグレードしても macOS は画面収録とアクセシビリティの許可を保持します。アップグレード後に許可が機能しなくなった場合は、[権限](#権限)の最後にある `tccutil` コマンドでリセットしてから、もう一度許可してください。

アプリは自動で最新の状態に保たれます。GitHub で新しいバージョンを確認し、アプリ内でインストールします（[アップデート](#アップデート)を参照）。

各リリースには、ソースコードの `.tar.gz` と `.zip`、および `SHA256SUMS.txt` ファイルも含まれています。ダウンロードしたファイルを検証するには、ダウンロードフォルダで `shasum -a 256 --ignore-missing -c SHA256SUMS.txt` を実行します。

## 権限

このアプリは以下のシステム権限を使います。いずれも「システム設定」>「プライバシーとセキュリティ」で許可します。設定ウインドウの「権限」ページには各権限の状態が表示され、許可を求めるボタンとシステム設定へのリンクがあります。

| 権限 | 用途 | 許可しない場合 |
| --- | --- | --- |
| 画面収録 | クライアントのウインドウのキャプチャと、ウインドウタイトルの読み取り | サムネイルにはプレースホルダが表示されます。アクセシビリティも許可していない場合はタイトルを読み取れず、クライアントは `EVE (PID)` と表示されます |
| アクセシビリティ | クライアントのウインドウの復元、前面への移動、最小化、ウインドウタイトルの読み取り、マウスのホットキーの横取り | クライアントのプロセスをアクティブにすることしかできないため、最小化したウインドウを復元できません。「最小化」と「すべて最小化」は無効になります。マウスのホットキーは動作しませんが、キーボードのホットキーは動作します |
| 「書類」フォルダ | 戦闘アラートが `~/Documents/EVE/logs/Gamelogs` を読み取ります。偵察オーバーレイと翻訳オーバーレイは `~/Documents/EVE/logs/Chatlogs` を読み取り、偵察オーバーレイは現在地を求めるためにゲームログも読み取ります | これらの機能のどれかをオンにしたとき、または「ログから追加」メニューで「更新」をクリックしたときだけ要求されます。拒否した場合はその機能のページに理由が表示され、ほかの機能には影響しません |
| ローカルネットワーク（macOS 15 以降） | ローカルネットワーク内の別のコンピュータで動く翻訳サービス（Ollama など）への接続 | 翻訳サービスがローカルネットワーク内の別のコンピュータにあるときだけ要求されます。この Mac や公開サービスでは要求されません。「翻訳」ページの「テスト」をクリックすると、先にこの確認を表示できます。拒否した場合、そのコンピュータへのリクエストはネットワークエラーで失敗します。「権限」ページには表示されません |

画面収録を許可した後、反映するには通常アプリの再起動が必要です。「権限」ページに「再起動」ボタンがあります。アクセシビリティはすぐに反映されます。

権限の記録がおかしな状態になった場合は、次の 2 つのコマンドを実行してから、権限を再度許可してください。

```sh
tccutil reset ScreenCapture io.github.deletexiumu.eveopreview-macos
tccutil reset Accessibility io.github.deletexiumu.eveopreview-macos
```

## 使い方

### サムネイルの操作

左ボタンを押した時点で、離すのを待たずにすぐ切り替わります。そのため、移動とサイズ変更には右ドラッグまたは Option+左ドラッグを使います。

| 操作 | ジェスチャ |
| --- | --- |
| クライアントに切り替える | 左ボタンを押す |
| クライアントを最小化する | Ctrl+左ボタンを押す |
| メニューを開く | 右クリック（押してから離すまでの移動が 4 ポイント未満） |
| 移動 | 右ドラッグ、または Option+左ドラッグ |
| サイズ変更 | 移動と同じジェスチャを、サムネイルの端から 12 ポイント以内で始めます |
| スナップを一時的に無効にする | ドラッグ中に Shift を押し続けます。サイズ変更中は、Shift で縦横比も保持されます |

「レイアウトをロック」をオンにすると、移動とサイズ変更は無効になります。切り替え、最小化、メニューは引き続き使えます。

### ホットキー

ホットキーは、設定ウインドウの「切り替えとホットキー」ページで記録します。ボタンをクリックしてから、キーの組み合わせかマウスボタンを押します。Esc でキャンセル、Delete で消去します。1 つの動作に複数の割り当てを設定できます。

- サイクルグループ：各グループには進むホットキーと戻るホットキーがあり、グループ内のキャラクターのうち、オンラインでスキップされていないキャラクターを順に切り替えます。最後まで進むと最初に戻ります。
- キャラクターごとのホットキー：そのキャラクターのクライアントに切り替えます。
- 共通ホットキー：すべてのサムネイルの表示／非表示、すべて最小化、ログイン画面のクライアントの順次切り替え。

キーボードのホットキーには、Ctrl、Option、Command のいずれかを含めてください。F1〜F20 とテンキーの数字は単独で使えます。Cmd+Tab、Cmd+Space、Cmd+Q などのシステムの組み合わせは受け付けません。ホットキーに問題がある場合は、設定ウインドウでそのホットキーの横に理由が表示されます。

マウスのホットキー：

- 中ボタンとサイドボタンを記録できます（設定ファイルでは `Mouse3`〜`Mouse32` と書きます）。`ctrl+Mouse4` のように修飾キーと組み合わせることもできます。左ボタンと右ボタンは割り当てられません。
- ホットキーが発動すると、そのクリック（押す、ドラッグ、離す）は前面のアプリに渡されません。そのため、同じボタンに割り当てたゲーム内の操作は実行されません。
- マウスのホットキーには、アクセシビリティの権限が必要です。

範囲：

- 各ホットキーは「グローバル」か「EVE 内のみ」にでき、設定ファイルではサフィックス `@global` または `@game` で表します。サフィックスのないホットキーは、プロファイルのデフォルトの範囲に従います。
- 「EVE 内のみ」のホットキーは、EVE クライアントが前面にあるときだけ動作します。ほかのアプリでは、キー入力は通常どおりそのアプリに渡されます。
- 新しく記録したマウスのホットキーは「EVE 内のみ」がデフォルトです。そのため、サイドボタンがすべてのアプリで横取りされることはありません。
- メニューバーのメニューにある「ホットキーを EVE 内のみで有効にする」で、デフォルトの範囲を切り替えます。

### 戦闘アラート

設定ウインドウの「アラート」ページでオンにします。オンにすると、アプリはクライアントが `~/Documents/EVE/logs/Gamelogs` に書き出すゲームログを読み取り、ログヘッダーのリスナーで各ログをキャラクターに対応付けます。キャラクターが攻撃されると、そのキャラクターのサムネイルの枠線と画像を 3 秒間点滅させます。

- EVE クライアントでゲームログの記録が有効になっている必要があります（デフォルトで有効です）。
- 外れた攻撃でも、デフォルトでアラートが出ます。これはオフにできます。最小ダメージ、点滅の色、持続時間を設定できます。
- 「EVEが前面にないときはサムネイルを隠す」をオンにしている場合、攻撃されたキャラクターのサムネイルは一時的に表示されます。
- システム設定で「視差効果を減らす」をオンにしている場合、点滅の代わりに点灯したままのハイライトが表示されます。
- アプリはログを読むだけです。ログを書き込んだり変更したりすることはなく、ゲームに入力も送りません。
- 初回は、macOS が「書類」フォルダへのアクセスを求めます。ログが別の場所にある場合は、「アラート」ページでフォルダを選択してください。
- 中国語クライアントのログ形式は、実際のログで確認済みです。日本語とロシア語のダメージの行は、実際のクライアントログ（上流が記録したサンプル）で確認済みですが、外れた攻撃の行はテンプレートから推測しただけです。英語、ドイツ語、フランス語、スペイン語、韓国語は上流のテンプレートから推測したもので、実際のログでは確認していません。

### 偵察オーバーレイ

設定ウインドウの「偵察」ページの「偵察オーバーレイを表示」、またはメニューバーのメニューの「偵察オーバーレイを表示」でオンにします。オンにすると、アプリはクライアントが `~/Documents/EVE/logs/Chatlogs` に書き出すチャットログを読み取ります。このフォルダは、「アラート」ページで選んだゲームログのフォルダと同じ階層にあります。オーバーレイの各行は偵察チャンネルの 1 件のメッセージで、経過時間、各星系とそのセキュリティステータスと現在地からのジャンプ数、敵の人数、艦船、パイロット名を表示します。

- EVE クライアントで、チャットをファイルに記録する設定をオンにしておく必要があります。
- クライアントの言語が英語以外のとき、Mac 版 EVE はローカル、コーポ、アライアンスのログを書き出さないことがあります（中国語で確認）。その場合、両方のオーバーレイでこれらのチャンネルは空のままです。EVE の言語を English にしてキャラクターでログインし直してください。この状態のとき、翻訳オーバーレイの状態行に表示されます。
- チャンネル：「ログから追加」で最近のチャットログにあるチャンネルから選ぶか（各項目には、そのチャンネルにいる自分のキャラクターの数が表示されます）、チャンネル名を入力して Return キーを押します。ログフォルダを読み取るのは、機能がオンのとき、または「ログから追加」メニューで「更新」をクリックしたときだけです。機能がオフの間、メニューには最初「更新」だけが表示されます（「翻訳」ページでは組み込みチャンネルも表示されます）。チャンネルは最大 16 個です。個人間の会話は読み取らず、一覧にも表示しません。
- オンにすると、オーバーレイには直近 30 分のメッセージが表示されます（「保持する期間」、5〜120 分）。古い行は消えます。
- 現在地：ジャンプ数は、アクティブなキャラクターがいる星系から数えます。アプリは、ゲームログのジャンプとドック解除の行、および Local チャットログの星系移動のメッセージから現在地を取得します。どちらもない場合は、「現在地」でそのキャラクターの星系名を入力して Return キーを押します。名前が見つからないときは「この星系が見つかりません」と表示されます。手動の現在地は次のジャンプで置き換えられ、再起動後も保持されます。現在地がまったくないキャラクターは、「基準星系」からジャンプ数を数えます。
- 「計算の上限」はジャンプ数の上限です（1〜30、デフォルトは 15）。「ハイライトの範囲」は、報告された星系がそのジャンプ数以内のときにメッセージをハイライトします（デフォルトは 5、0 でオフ）。「原文を表示」は、発言者とメッセージを 2 行目に追加します。
- 星系名と艦船名は UI 言語で表示します。
- パイロット名は、メッセージから星系、艦船、人数を認識した残りなので、空白を含む名前が続くと区切りがあいまいになります。「オンラインで名前を確認（ESI）」がオン（デフォルト）のとき、アプリは CCP の ESI に、それらの語のどれが実在するキャラクター名かを問い合わせ、その結果で区切ります（[プライバシー](#プライバシー)を参照）。一致は、その名前のキャラクターが存在することを示すだけで、メッセージが指すのがそのキャラクターであるとは限りません。一致した名前には、右クリックメニューの「ブラウザで開く」に zKillboard へのリンクが付きます。「名前のキャッシュを消去」で保存した名前を削除します。

### チャット翻訳

「翻訳」ページの「翻訳オーバーレイを表示」、またはメニューバーのメニューの「翻訳オーバーレイを表示」でオンにします。選んだチャンネルのメッセージのうち、翻訳先の言語でないものを翻訳します。

1. 偵察オーバーレイと同じ方法でチャンネルを選びます。「ログから追加」には、組み込みのローカル、コーポレーション、アライアンス、フリートのチャンネルも表示されます。
2. 「翻訳先」で言語を選ぶか、「インターフェイスの言語と同じ」（デフォルト）を選びます。
3. 「サービス」を選びます：DeepSeek（デフォルト）、Claude (Anthropic)、OpenAI、Qwen (DashScope)、Kimi (Moonshot)、Ollama、または「その他（OpenAI 互換）」。「API アドレス」と「モデル名」にはプリセットの値が表示されます。入力するとプリセットより優先されます。
4. API キーを貼り付けて「保存」をクリックします。キーは macOS のキーチェーンに保存され、「キーを削除」で削除できます。Ollama ではキーは不要です。
5. 「テスト」をクリックすると、固定のサンプル文を 1 つ翻訳します。

- モデルに送るのは、アクティブなクライアントのキャラクターが受け取ったメッセージだけです。同じ文は 1 回だけ翻訳し、以降はキャッシュから取ります。星系と艦船だけのメッセージは送りません。翻訳先が中国語、日本語、韓国語、ロシア語のときは、すでにその言語のメッセージも送りません。翻訳先が英語、ドイツ語、フランス語、スペイン語のときは、これらのメッセージをすべてモデルに送り、すでに翻訳先の言語かどうかはモデルが判断します。星系、リージョン、艦船の名前は翻訳先の言語の公式名を使います。
- 各行には、EVE 時間、チャンネル（翻訳するチャンネルが 2 つ以上のときだけ）、発言者、訳文を表示します。「原文も表示」は原文をその下に追加し、「翻訳したメッセージだけを表示」は、すでに翻訳先の言語なので飛ばしたメッセージと、モデルが翻訳先の言語だと判断したメッセージを隠します。
- サービスがキーを拒否したり、利用枠を使い切ったりすると翻訳は一時停止し、ステータス行に理由が表示されます。「今すぐ再試行」でもう一度試します。
- 公開アドレスでは `https` を使う必要があります。`http` は、この Mac かローカルネットワーク（例：Ollama の `http://127.0.0.1:11434/v1`）でのみ使えます。
- リクエストには、選んだサービスのご自身のアカウントを使うため、料金がかかる場合があります。
- 別の署名で再ビルドした後は、「テスト」や「今すぐ再試行」をクリックしたときに、macOS がキーチェーン項目の読み取りの許可を求めることがあります。バックグラウンドでの読み取りではこの確認を表示せず、代わりにステータス行でキーの再保存を求める設計です。実際に再ビルドしての確認は、まだ手作業で行う必要があります。

### オーバーレイの操作

偵察オーバーレイと翻訳オーバーレイは独立したパネルで、サムネイルと同じように動作します。フォーカスを奪わず、すべての操作スペースに表示され、前面の EVE ウインドウのキャラクターだけを表示し、クライアントを切り替えるとすぐに内容が切り替わります。クリックはゲームに届きません。最新のメッセージは一番下にあり、リストは一番下にとどまります。上にスクロールするとリストは新しいメッセージを追わなくなり、下部に「新着 N 件」のバーが表示されます。クリックすると最新に戻ります。

| 操作 | ジェスチャ |
| --- | --- |
| リストをスクロール | スクロールホイール、またはトラックパッドの 2 本指スワイプ |
| 移動 | 右ドラッグ、または Option+左ドラッグ |
| サイズ変更 | 移動と同じジェスチャを、オーバーレイの端から 12 ポイント以内で始めます |
| スナップを一時的に無効にする | ドラッグ中に Shift を押し続けます |
| メニューを開く | 右クリック（押してから離すまでの移動が 4 ポイント未満） |
| 最新に戻る | 「新着 N 件」のバーをクリック |

右クリックメニューには、「最新までスクロール」「この行をコピー」「ブラウザで開く」（リンクのある行だけ）「リストを消去」「レイアウトをロック」「位置とサイズをデフォルトに戻す」「このオーバーレイを隠す」「設定を開く…」があります。「背景の不透明度」（20%〜100%、背景だけ。文字は常に不透明）と「文字サイズ」（10〜24 ポイント）は各機能のページにあります。「レイアウトをロック」と「EVEが前面にないときはサムネイルを隠す」はオーバーレイにも適用されます。「すべてのサムネイルを隠す」はサムネイルだけが対象です。

### メニューバー

メニューバーのアイコンは、八角形の中に分子がある図案です。メニューには、「すべてのサムネイルを表示」または「すべてのサムネイルを隠す」、プロファイルの切り替え、「すべてのクライアントを最小化」、「ホットキーを EVE 内のみで有効にする」、「偵察オーバーレイを表示」、「翻訳オーバーレイを表示」、「アップデートを確認…」、「問題を報告…」、「設定…」、「EVE-O Previewを終了」があります。アップデートが利用可能なとき、または前回の実行が予期せず終了したときは、アイコンにドットが表示され、メニューの先頭にそのための項目が追加されます。権限が不足しているときは、それに関する項目がメニューに追加されます。システムの収録インジケータからクライアントのキャプチャを停止した場合は、メニューに「キャプチャを再開」項目が追加されます。

EVE-O Preview は Dock にもアイコンを表示し、クリックすると設定ウインドウが開きます。メニューバーのアイコンだけにするには、「設定」>「一般」で「Dock にアイコンを表示」をオフにします。

### アップデート

EVE-O Preview は、起動時と 1 日に 1 回、新しいリリースを確認します。確認には Cloudflare の CDN から配信される署名付きのアップデート一覧を使い、GitHub を予備にします。Windows 版だけを変更したリリースは通知されず、リリースノートも macOS の部分だけが表示されます。これをオフにするには、「設定」>「一般」>「アップデート」で「アップデートを自動的に確認」のチェックを外します。その場合も、メニューバーのメニューにある「アップデートを確認…」でいつでも確認できます。

新しいバージョンが利用可能になると、ウインドウにインターフェイスの言語でリリースノートが表示され（翻訳がない場合は英語）、「アップデートをインストール」「このバージョンをスキップ」「あとで」を選べます。EVE クライアントが前面にある間は、ほかのアプリに切り替えるまでウインドウは表示されず、ウインドウが自分からキーボードフォーカスを奪うこともありません。メニューバーのアイコンのドットは、アップデートが待機中であることを示します。「このバージョンをスキップ」はそのバージョンの自動通知を止めるだけで、「アップデートを確認…」では引き続き表示されます。

「アップデートをインストール」は dmg をダウンロードし、`SHA256SUMS.txt` と照合し、新しいアプリが実行中のアプリと同じ証明書で署名されていることを検証してから、アプリを置き換えて再起動します。いずれかの手順が失敗した場合、インストール済みのアプリは変更されません。「アップデートを自動的にインストール」は初期設定でオンです。アップデートはバックグラウンドでダウンロードされ、EVE クライアントが約 1 分間起動しておらず、EVE-O Preview のウインドウも開いていなければ、インストールしてアプリを再起動します。それ以外の場合は、EVE-O Preview を終了したとき、またはメニューバーのメニューで「再起動して X.Y.Z にアップデート」を選んだときにインストールされます。EVE クライアントの実行中に、アプリが勝手に再起動することはありません。先にウインドウで確認したい場合は、「設定」>「一般」>「アップデート」でオフにします。

次のビルドでは、インストールの代わりに理由と「リリースページを開く」ボタンだけが表示されます：ad-hoc 署名またはローカルで署名されたビルド、ディスクイメージから実行しているアプリ、またはトランスロケーションされた場所から実行しているアプリ、書き込み権限のないフォルダにあるアプリ、APFS 以外のボリューム（HFS+、exFAT、FAT の外部ディスクなど）上のアプリ。

### 問題を報告

メニューバーのメニューまたは「一般」ページで「問題を報告…」を選ぶか、EVE-O Preview が予期せず終了した後に表示される確認に応答します。ウインドウには、レポートに含まれるすべてのファイルが一覧表示され、個人情報を伏せた後の内容が表示されます：環境の概要、名前を含まない設定の概要、アプリのログ（最大 2 MiB）、最大 3 件の macOS のクラッシュレポート。「レポートのみ作成」または「レポートを作成して GitHub を開く」をクリックするまで、何も作成されません。zip は `~/Library/Application Support/EVE-O Preview/Reports/` に保存され（新しいものから 3 件を保持）、Finder に表示されます。「レポートを作成して GitHub を開く」では、内容を記入済みの Issue もブラウザで開きます。zip はご自身で添付してください。アプリが何かをアップロードすることはありません。

macOS のユーザー名、フルネーム、ホームフォルダのパス、コンピュータ名は `[user]` と `[host]` に置き換えられます。EVE のキャラクター名は `[character-1]`、`[character-2]` のように置き換えられ、クラッシュレポートのデバイス識別子は `[redacted]` に置き換えられます。置き換えられるのはアプリが知っている名前だけです。設定にも実行中のクライアントとしても一度も現れなかったキャラクターの名前は置き換えられません。名前が一般的な単語の場合は、ログのほかの場所にある同じ単語も置き換えられます。レポートを作成する前にすべてのファイルを読むことができ、含めたくないファイルのチェックを外せます。

アプリは `~/Library/Logs/EVE-O Preview/` に、1 ファイル 1 MiB のログファイルを最大 5 個保持します。キャラクター名とウインドウタイトルは `<private>` と記録されます。「一般」ページで「詳細ログ」をオンにすると、デバッグ用の行も記録されます。「Finder でログを表示」でフォルダを開けます。クラッシュの後に確認が表示されない場合は、`~/Library/Logs/DiagnosticReports/EVEOPreview-<date>.ips` を手動で Issue に添付してください。

## プライバシー

アプリはアップデートのために Cloudflare と GitHub に接続します。このリストの後で説明するオプション機能をオンにしない限り、ほかの接続は行いません。

- アップデートの確認：「アップデートを自動的に確認」がオンの間は起動時と 1 日に 1 回、また「アップデートを確認…」を選んだときに、署名付きのアップデート一覧 `eveo.deepai.wiki/update-manifest.json`（Cloudflare が配信）をダウンロードします。失敗したときは `github.com/deletexiumu/eve-o-preview/releases/latest/download/update-manifest.json` を使います。一覧には以前のバージョンの変更内容も含まれているため、スキップしたバージョンを表示するための追加のリクエストはありません。
- アップデートのインストール：`eveo.deepai.wiki` から `SHA256SUMS.txt` と dmg をダウンロードし、失敗したときは GitHub のリリースからダウンロードします。どのファイルも署名付きの一覧と照合します。

リクエストに含まれるのは、`User-Agent` ヘッダーのアプリのバージョン、固定の `Accept-Language: en`、`Cache-Control: no-cache` だけです。キャラクター名、設定、ログ、ハードウェアの詳細、システムのバージョン、識別子は送信されず、Cookie も使いません。Cloudflare と GitHub に見えるのは、IP アドレスとリクエストの時刻です。テレメトリはなく、クラッシュ情報の自動アップロードもありません。「問題を報告…」は Mac 上に zip を作成し、Web ページを開くだけです。送信するかどうかはご自身で決めます。

偵察オーバーレイと翻訳オーバーレイは、チャットログとゲームログを読み取るだけで、書き込むことはありません。個人間の会話は読み取りません。次の 2 つのオプション機能はほかのサービスに接続します。

- パイロット名の確認：偵察オーバーレイをオンにすると、「オンラインで名前を確認（ESI）」はデフォルトでオンです。アクティブなキャラクターが受け取った偵察メッセージに、2 語以上のパイロット名が続けて含まれているとき、アプリはそれらの語を、単独で、および 3 語までの組み合わせで、CCP の ESI（`esi.evetech.net/universe/ids`）に送ります。発言者、チャンネル、メッセージの残りは送りません。自分のキャラクター名が含まれるのは、だれかがそれを偵察メッセージに書いた場合だけです。1 語だけで単独に現れる名前は問い合わせません。CCP には、IP アドレスと、アプリのバージョンとプロジェクトの URL を含む `User-Agent` ヘッダーが見えます。これらのリクエストを止めるには、「偵察」ページでこの設定をオフにします。アプリ自体は zKillboard に接続しません。「ブラウザで開く」はキャラクターの zKillboard ページをブラウザで開くだけで、アドレスに含まれるのはキャラクター ID だけです。
- チャット翻訳（デフォルトはオフ）：翻訳チャンネルでアクティブなクライアントのキャラクターが受け取ったメッセージの本文を、そこに出てくる星系と艦船の公式名とともに、「翻訳」ページで選んだモデルサービスに送ります。発言者名とチャンネル名は送りません。「テスト」は固定のサンプル文を 1 つ送ります。API キーは macOS のキーチェーンにだけ、サービス `io.github.deletexiumu.eveopreview-macos.translation` の項目（モデルサービスごとに 1 つ）として保存され、そのモデルサービスにだけ送られます。設定ファイル、ログ、問題レポートに含まれることはありません。公開アドレスでは `https` を使う必要があり、`http` はこの Mac かローカルネットワーク（例：Ollama）でのみ使えます。サービスがテキストをどう扱うかは、そのサービスの規約に従います。

問題レポートには、これらの機能の設定が数値とオン／オフ（チャンネル数や選んだサービスなど）として含まれますが、チャンネル名、星系名、API アドレス、モデル名、パイロット名、チャット本文、キーは含まれません。

アプリは次の場所にデータを保存します。完全にアンインストールするには、アプリと一緒にこれらと `~/Library/Application Support/EVE-O Preview/config.json` を削除します。

| 場所 | 内容 |
| --- | --- |
| `~/Library/Logs/EVE-O Preview/` | アプリのログ。最大で約 5 MiB |
| `~/Library/Application Support/EVE-O Preview/session.json`、`state.json` | セッションのマーカー。アップデートと診断の記録。偵察の手動の現在地 |
| `~/Library/Application Support/EVE-O Preview/Reports/` | 作成した問題レポートの zip。個人情報は伏せられています（新しいものから 3 件） |
| `~/Library/Caches/io.github.deletexiumu.eveopreview-macos/Updates/` | ダウンロードしたアップデートファイル。インストール後に削除されます |
| `~/Library/Application Support/EVE-O Preview/pilot-names.json` | ESI で一致したパイロット名とキャラクター ID（ゲームの公開データ）。30 日間保持します。本人だけが読み書きでき（0600）、問題レポートには含まれません。「偵察」ページの「名前のキャッシュを消去」で空にします。一致しなかった名前はメモリに 6 時間だけ保持します |
| `~/Library/Application Support/EVE-O Preview/translation-cache.json` | メッセージの原文と訳文。発言者名とチャンネル名は含みません。本人だけが読み書きでき（0600）、問題レポートには含まれません。「翻訳」ページの「キャッシュを消去」で空にします |
| サービスが `io.github.deletexiumu.eveopreview-macos.translation` のキーチェーン項目 | 翻訳用の API キー。モデルサービスごとに 1 つ。「翻訳」ページの「キーを削除」で現在のモデルサービスの項目を削除します |

## 設定ファイル

設定は `~/Library/Application Support/EVE-O Preview/config.json` に保存されます。1 つのファイルにすべてのプロファイルが入っています。

- 変更は、変更してから 0.5 秒後に自動で保存され、終了時にももう一度保存されます。
- ファイルが破損している場合は `config.corrupt-<date-time>.json` に名前が変更され、アプリはデフォルト設定を使います。
- ファイルが新しいバージョンで作られたものである場合、アプリはデフォルト設定で動作します。そのセッション中はディスクに書き込まず、ファイルを上書きしません。

「プロファイル」ページに「Finderに表示」ボタンがあります。

## 移植していない上流の機能

| 上流の機能 | 理由 |
| --- | --- |
| フレームレート制限と選択的ミュート（Robin インジェクション） | 上流は Windows のプロセスに DLL を注入しています。macOS には同等の公開された仕組みがありません。Windows 版は代わりにグラフィックスドライバーでフレームレートを制限します（[Windows](#windows) を参照） |
| CPU アフィニティ | Windows の CPU Sets に依存しています。Apple Silicon にはプロセスを特定のコアに固定する公開 API がありません |
| 戦闘ログの Augments：ダメージの数値、DPS、リペア量、星系オーバーレイ、FC 用の静的データ | 「プレビューと切り替え」の範囲外にある、大規模な別のサブシステムです。移植したのは「攻撃されたら点滅」だけです |
| テーマ、レガシー UI、右クリックメニューのカスタムスタイル | macOS 版はシステムの外観に従います |
| 互換キャプチャモード（`PrintWindow`） | キャプチャ方法は ScreenCaptureKit だけです |
| 低レベルキーボードフック | キーボードのホットキーには Carbon のグローバルホットキーを使います。マウスのイベントタップは、マウスボタンが割り当てられたときだけ作成します |

ドラッグ＆ドロップでドッキングできるリージョン、複数選択とグループ移動、取り消し、スナップガイド、Windows 版の設定のインポート、ログイン時の起動は、v1 のリリース後に予定しています。

## 免責事項

このツールはウインドウのフォーカスを切り替えるだけです。複数のクライアントに入力をブロードキャストすることはなく、ゲームのメモリを読み取ったり変更したりすることもありません。これは上流と同じ範囲です。偵察オーバーレイと翻訳オーバーレイは、クライアントが書き出すログファイルを読み取るだけです。使用する前に、EVE Online のエンドユーザー使用許諾契約書をお読みください。

アプリはアップデートの確認とダウンロードのために GitHub に接続します。CCP の ESI と翻訳サービスに接続するのは、それらのオプション機能をオンにしたときだけで、送信する内容は[プライバシー](#プライバシー)に書いたものだけです。

EVE Online および関連するロゴは CCP ehf. の商標です。このプロジェクトは CCP とは関係がなく、CCP の承認も受けていません。

アプリのアイコンは、プロジェクトのメンテナーが用意したデフォルメの死神です。`shared/branding/make-icons.py` が `shared/branding/logo-source.jpg` から macOS と Windows のアイコンを生成します。CCP の商標やゲームのアートワークは含まれていません。
