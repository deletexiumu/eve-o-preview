# EVE-O Preview for macOS

[English](README.md) | [简体中文](README.zh-CN.md) | [日本語](README.ja.md) | **한국어** | [Русский](README.ru.md) | [Français](README.fr.md) | [Deutsch](README.de.md) | [Español](README.es.md)

이 번역은 기계 번역이며, 영어 원문과 내용이 다를 경우 [영어 README](README.md)가 우선합니다.

EVE-O Preview for macOS는 실행 중인 모든 EVE Online 클라이언트의 실시간 썸네일을 보여 줍니다. 썸네일을 클릭하거나 전역 단축키를 누르면 해당 클라이언트로 전환합니다.

이 앱은 [EveOPlus/eve-o-preview](https://github.com/EveOPlus/eve-o-preview)(Windows, GPL-3.0)의 기능을 macOS용 네이티브 Swift로 새로 구현한 것입니다. 원본 프로젝트의 C# 코드를 이식하지 않았으며, UI와 설정 파일 형식도 원본 프로젝트와 다릅니다.
라이선스는 GNU General Public License 버전 3 또는 그 이후 버전(GPL-3.0-or-later)이며, 소스 파일의 SPDX 식별자와 일치합니다. 원본 프로젝트의 라이선스는 GPL-3.0입니다. 전문은 [LICENSE](LICENSE)를 참고하십시오.

이 저장소는 처음에 EveOPlus/eve-o-preview의 GitHub 포크로 만들어졌으며, v1.0부터 독립 저장소로 옮겼습니다. 이 프로젝트는 독립 프로젝트로, Windows 버전과 코드를 공유하지 않으며 원본 프로젝트의 작성자가 관리하지 않습니다.

## 기능

- 클라이언트 감지: 클라이언트가 시작되거나 종료될 때, 또는 로그인 후 이름이 바뀔 때 썸네일이 자동으로 갱신됩니다.
- 실시간 썸네일: 클라이언트마다 ScreenCaptureKit 스트림 하나를 사용하며, 크기와 프레임 속도를 조절할 수 있습니다.
- 썸네일 패널: 포커스를 가져가지 않고, 모든 Spaces에 표시되며, 선택에 따라 항상 위에 표시할 수 있습니다. 인접한 썸네일을 쉽게 구분할 수 있도록 기본적으로 2포인트 두께의 밝은 회색 테두리가 있습니다. 색상과 두께는 조절할 수 있고, 테두리를 끌 수도 있습니다.
- 전환: 썸네일을 왼쪽 클릭하면 해당 클라이언트로 전환하고, Ctrl+클릭하면 최소화합니다. 오른쪽 클릭 메뉴에는 최소화, 모두 최소화, 순환에서 건너뛰기, 이 썸네일 가리기, 기본 크기로 되돌리기가 있습니다.
- 오버레이: 캐릭터 이름 제목, 활성 클라이언트의 강조 표시 테두리(캐릭터별로 색상 설정 가능, 표시되는 동안 밝은 회색 테두리를 대신함), 순환 건너뛰기 표시.
- 마우스 오버 확대(기준점 9개)와 불투명도.
- 표시 여부: 활성 클라이언트의 썸네일 가리기, EVE가 앞에 있지 않을 때 가리기(지연 시간 적용), 캐릭터별 가리기, 모두 가리기.
- 레이아웃: 드래그하여 이동하고 크기를 조절하며, 다른 썸네일과 화면 가장자리에 자석 맞춤이 적용되고, 선택에 따라 레이아웃을 잠글 수 있습니다. 위치와 크기는 캐릭터별로 저장되며, 로그인 화면의 클라이언트는 별도의 시작 위치를 사용합니다.
- 순환 그룹: 앞으로 단축키와 뒤로 단축키, 현재 세션 동안 건너뛰기, 캐릭터별 단축키, 로그인 화면 클라이언트를 순환하는 단축키, 모두 가리기 단축키와 모두 최소화 단축키. 단축키에는 마우스 가운데 버튼과 측면 버튼을 쓸 수 있으며, 각 단축키는 전역으로 또는 EVE 안에서만 작동하도록 설정할 수 있습니다.
- 전투 알림(기본값은 꺼짐): 게임 로그를 읽어, 캐릭터가 공격받으면 해당 캐릭터의 썸네일을 깜박입니다.
- 정찰 오버레이(기본값은 꺼짐): 지정한 정찰 채널의 채팅 로그를 읽어, 앞에 있는 EVE 윈도우의 캐릭터를 기준으로 적이 어느 성계에서 보고되었는지, 몇 점프 떨어져 있는지, 몇 명인지, 어떤 함선인지 표시합니다([정찰 오버레이](#정찰-오버레이) 참고).
- 채팅 번역 오버레이(기본값은 꺼짐): 지정한 채널에서 다른 언어로 된 메시지를, 직접 고른 모델 서비스와 본인의 API 키로 사용자의 언어로 번역합니다([채팅 번역](#채팅-번역) 참고).
- 프로필: 생성, 복제, 이름 변경, 삭제, 전환.
- 업데이트: GitHub에서 새 릴리스를 확인하고, 다운로드한 파일과 코드 서명을 검증한 뒤 앱 안에서 설치합니다([업데이트](#업데이트) 참고).
- 문제 보고서: 민감한 정보를 가린 진단 zip을 만들고 미리 채워진 GitHub 이슈를 엽니다. 앱이 예기치 않게 종료되면 다음 실행 때 신고할지 묻습니다([문제 신고](#문제-신고) 참고).
- Windows 트레이 아이콘 대신 메뉴 막대 아이콘.
- 10개 페이지로 된 설정 윈도우: 클라이언트, 썸네일 및 레이아웃, 전환 및 단축키, 알림, 정찰, 번역, 프로필, 일반, 권한, 정보.
- UI 언어: 영어(기본값), 중국어, 러시아어, 일본어, 한국어, 프랑스어, 독일어, 스페인어. 일반 페이지에서 전환하거나 "시스템 설정 따르기"를 선택할 수 있으며, 변경 사항은 즉시 적용됩니다. 러시아어, 일본어, 한국어, 프랑스어, 독일어, 스페인어 번역은 기계 번역이며, 수정 제안을 환영합니다.

## 요구 사항

- macOS 14 이상, Apple Silicon 또는 Intel. 릴리스 dmg에는 유니버설 바이너리가 들어 있습니다.
- EVE 클라이언트는 창 모드로 실행하는 것이 좋습니다. 1.1.1부터 네이티브 전체 화면 클라이언트도 지원하지만("썸네일을 항상 위에 표시"가 켜져 있으면 썸네일이 전체 화면 위에 표시됩니다), 각 클라이언트가 자체 Space에 있으므로 전환할 때 Space 전환 애니메이션이 재생됩니다.

## 설치

### 릴리스 다운로드

1. [Releases](https://github.com/deletexiumu/eve-o-preview/releases) 페이지에서 `EVE-O-Preview-<version>.dmg`를 다운로드합니다.
2. dmg를 열고 `EVE-O Preview.app`을 응용 프로그램 폴더로 드래그합니다.
3. 앱을 엽니다. 메뉴 막대에 아이콘이 나타나며, 처음 실행하면 설정 윈도우가 권한 페이지로 열립니다.

이 프로젝트에는 Apple Developer ID가 없으므로 릴리스 빌드는 이 프로젝트 자체의 자체 서명 인증서로 서명되어 있고 공증을 받지 않았습니다. 처음 실행하면 macOS가 개발자를 확인할 수 없다는 메시지와 함께 앱을 차단합니다. 앱을 열려면 다음과 같이 합니다.

1. 시스템 설정 > 개인정보 보호 및 보안을 엽니다.
2. 아래로 스크롤하여 EVE-O Preview에 관한 메시지에서 "그래도 열기"를 클릭한 다음 확인합니다.

macOS에서 앱이 "손상되었기 때문에 열 수 없습니다"라고 표시되거나 위 단계 대신 다른 방법을 쓰려면 터미널에서 격리 속성을 제거합니다.

```sh
xattr -dr com.apple.quarantine "/Applications/EVE-O Preview.app"
```

**참고:** 모든 릴리스는 같은 인증서로 서명되므로 업그레이드해도 macOS가 화면 기록과 손쉬운 사용 권한을 유지합니다. 업그레이드 후 권한이 동작하지 않으면 [권한](#권한) 섹션 끝에 있는 `tccutil` 명령으로 초기화한 뒤 다시 허용하십시오.

앱은 스스로 최신 상태를 유지합니다. GitHub에서 새 버전을 확인하고 앱 안에서 설치합니다([업데이트](#업데이트) 참고).

각 릴리스에는 `.tar.gz`와 `.zip` 형식의 소스 코드, 그리고 `SHA256SUMS.txt` 파일도 포함되어 있습니다. 다운로드한 파일을 검증하려면 다운로드 폴더에서 `shasum -a 256 --ignore-missing -c SHA256SUMS.txt`를 실행합니다.

### 소스에서 빌드

앱을 직접 빌드하려면 [docs/macos/development.md](docs/macos/development.md)(영어)를 참고하십시오. 디버깅 도구, CI, 릴리스 절차도 그곳에 설명되어 있습니다.

## 권한

이 앱은 아래의 시스템 권한을 사용하며, 모두 시스템 설정 > 개인정보 보호 및 보안에서 허용합니다. 설정 윈도우의 권한 페이지에서 각 권한의 상태를 확인할 수 있으며, 요청 버튼과 시스템 설정으로 가는 링크도 있습니다.

| 권한 | 용도 | 없을 때 |
| --- | --- | --- |
| 화면 기록 | 클라이언트 윈도우 캡처 및 윈도우 제목 읽기 | 썸네일에 자리 표시자가 표시됩니다. 손쉬운 사용 권한도 없으면 제목을 읽을 수 없어 클라이언트가 `EVE (PID)`로 표시됩니다 |
| 손쉬운 사용 | 클라이언트 윈도우 복원, 앞으로 가져오기, 최소화, 윈도우 제목 읽기, 마우스 단축키 가로채기 | 클라이언트 프로세스만 활성화할 수 있으므로 최소화된 윈도우를 복원할 수 없습니다. 최소화와 모두 최소화가 비활성화됩니다. 마우스 단축키는 작동하지 않지만 키보드 단축키는 계속 작동합니다 |
| 문서 폴더 | 전투 알림이 `~/Documents/EVE/logs/Gamelogs`를 읽음. 정찰 오버레이와 번역 오버레이는 `~/Documents/EVE/logs/Chatlogs`를 읽고, 정찰 오버레이는 위치를 알아내기 위해 게임 로그도 읽음 | 이 기능 중 하나를 켜거나 "로그에서 추가" 메뉴에서 "새로 고침"을 클릭할 때만 요청합니다. 거부하면 해당 기능의 페이지에 이유가 표시되며, 다른 기능에는 영향이 없습니다 |
| 로컬 네트워크(macOS 15 이상) | 로컬 네트워크의 다른 컴퓨터에서 실행되는 번역 서비스(Ollama 등)에 연결 | 번역 서비스가 로컬 네트워크의 다른 컴퓨터에 있을 때만 요청하며, 이 Mac이나 공개 서비스에는 요청하지 않습니다. 번역 페이지에서 "테스트"를 클릭하면 이 확인 창을 먼저 띄울 수 있습니다. 거부하면 그 컴퓨터로 보내는 요청이 네트워크 오류로 실패합니다. 권한 페이지에는 표시되지 않습니다 |

화면 기록을 허용한 뒤에는 보통 앱을 다시 시작해야 적용됩니다. 권한 페이지에 다시 실행 버튼이 있습니다. 손쉬운 사용은 즉시 적용됩니다.

권한 기록이 잘못된 상태가 되면 다음 두 명령을 실행한 뒤 권한을 다시 허용하십시오.

```sh
tccutil reset ScreenCapture io.github.deletexiumu.eveopreview-macos
tccutil reset Accessibility io.github.deletexiumu.eveopreview-macos
```

## 사용법

### 썸네일 제스처

왼쪽 버튼을 누르는 즉시 전환하며 버튼을 놓을 때까지 기다리지 않습니다. 그래서 이동과 크기 조절에는 오른쪽 드래그나 Option+왼쪽 드래그를 사용합니다.

| 작업 | 제스처 |
| --- | --- |
| 클라이언트로 전환 | 왼쪽 버튼 누르기 |
| 클라이언트 최소화 | Ctrl+왼쪽 버튼 누르기 |
| 메뉴 열기 | 오른쪽 클릭(누른 뒤 놓을 때까지 4포인트 미만으로 이동) |
| 이동 | 오른쪽 드래그 또는 Option+왼쪽 드래그 |
| 크기 조절 | 이동과 같은 제스처를 썸네일 가장자리에서 12포인트 이내에서 시작 |
| 자석 맞춤 일시 해제 | 드래그하는 동안 Shift를 누릅니다. 크기를 조절할 때는 Shift를 누르면 가로세로 비율도 유지됩니다 |

"레이아웃 잠금"을 켜면 이동과 크기 조절이 작동하지 않습니다. 전환, 최소화, 메뉴는 계속 작동합니다.

### 단축키

설정 윈도우의 전환 및 단축키 페이지에서 단축키를 등록합니다. 버튼을 클릭한 다음 키 조합이나 마우스 버튼을 누르십시오. Esc는 취소, Delete는 지우기입니다. 하나의 동작에 여러 개의 할당을 지정할 수 있습니다.

- 순환 그룹: 각 그룹에는 앞으로 단축키와 뒤로 단축키가 있으며, 그룹의 캐릭터 중 온라인 상태이고 건너뛰지 않은 캐릭터 사이를 순서대로 전환하고, 끝에 도달하면 처음으로 돌아갑니다.
- 캐릭터 단축키: 해당 캐릭터의 클라이언트로 전환합니다.
- 공통 단축키: 모든 썸네일 보기 또는 숨기기, 모든 클라이언트 최소화, 로그인 화면의 클라이언트 순환.

키보드 단축키에는 Ctrl, Option, Command 중 하나를 포함해야 합니다. F1–F20과 숫자 키패드는 단독으로 쓸 수 있습니다. Cmd+Tab, Cmd+Space, Cmd+Q 같은 시스템 조합은 거부됩니다. 단축키에 문제가 있으면 설정 윈도우에서 해당 단축키 옆에 이유를 표시합니다.

마우스 단축키:

- 가운데 버튼과 측면 버튼을 등록할 수 있으며(설정 파일에는 `Mouse3`–`Mouse32`로 기록됨), `ctrl+Mouse4`처럼 보조 키와 함께 쓸 수도 있습니다. 왼쪽 버튼과 오른쪽 버튼은 할당할 수 없습니다.
- 단축키가 작동하면 해당 클릭(누르기, 드래그, 놓기)은 앞에 있는 앱에 전달되지 않으므로, 같은 버튼에 할당된 게임 동작은 실행되지 않습니다.
- 마우스 단축키에는 손쉬운 사용 권한이 필요합니다.

범위:

- 각 단축키는 "전역" 또는 "EVE 안에서만"으로 설정할 수 있으며, 설정 파일에는 접미사 `@global` 또는 `@game`으로 기록됩니다. 접미사가 없는 단축키는 프로필의 기본 범위를 따릅니다.
- "EVE 안에서만" 단축키는 EVE 클라이언트가 앞에 있을 때만 작동합니다. 다른 앱에서는 키 입력이 평소처럼 해당 앱에 전달됩니다.
- 새로 등록한 마우스 단축키의 기본값은 EVE 안에서만이므로, 측면 버튼이 모든 앱에서 가로채이지 않습니다.
- 메뉴 막대 메뉴의 "단축키를 EVE 안에서만 사용"은 기본 범위를 전환합니다.

### 전투 알림

설정 윈도우의 알림 페이지에서 켭니다. 그러면 앱은 클라이언트가 `~/Documents/EVE/logs/Gamelogs`에 기록하는 게임 로그를 읽고, 로그 헤더의 수신자(Listener)를 기준으로 각 로그를 캐릭터에 연결하며, 캐릭터가 공격받으면 해당 캐릭터의 썸네일 테두리와 이미지를 3초 동안 깜박입니다.

- EVE 클라이언트에서 게임 로그 기록이 켜져 있어야 합니다(기본값은 켜짐).
- 빗나간 공격도 기본적으로 알림을 발생시키며, 이 동작은 끌 수 있습니다. 최소 피해량, 깜박임 색상, 지속 시간을 설정할 수 있습니다.
- "EVE가 앞에 있지 않으면 썸네일 가리기"를 켠 경우, 공격받은 캐릭터의 썸네일은 일시적으로 표시됩니다.
- 시스템 설정에서 "동작 줄이기"를 켜면 깜박임 대신 고정된 강조 표시가 나타납니다.
- 앱은 로그를 읽기만 합니다. 로그를 쓰거나 수정하지 않으며, 게임에 입력을 보내지 않습니다.
- 처음에는 macOS가 문서 폴더에 대한 접근 권한을 요청합니다. 로그가 다른 위치에 있으면 알림 페이지에서 폴더를 선택하십시오.
- 중국어 클라이언트의 로그 형식은 실제 로그로 확인했습니다. 일본어와 러시아어의 피해 줄은 실제 클라이언트 로그(원본 프로젝트가 기록한 샘플)로 확인했으며, 빗나감 줄은 템플릿으로만 추론했습니다. 영어, 독일어, 프랑스어, 스페인어, 한국어는 원본 프로젝트의 템플릿으로 추론했으며 실제 로그로 확인하지 않았습니다.

### 정찰 오버레이

설정 윈도우의 정찰 페이지에서 "정찰 오버레이 표시"를 켜거나, 메뉴 막대 메뉴에서 "정찰 오버레이 표시"를 선택합니다. 그러면 앱은 클라이언트가 `~/Documents/EVE/logs/Chatlogs`에 기록하는 채팅 로그를 읽습니다. 이 폴더는 알림 페이지에서 고른 게임 로그 폴더와 같은 위치에 있습니다. 오버레이의 각 줄은 정찰 채널의 메시지 하나로, 경과 시간, 각 성계와 그 보안 등급 및 현재 위치로부터의 점프 수, 적의 수, 함선, 파일럿 이름을 보여 줍니다.

- EVE 클라이언트에서 채팅을 파일로 기록하도록 설정해야 합니다.
- 클라이언트 언어가 영어가 아니면 Mac용 EVE가 Local, Corp, Alliance 로그를 기록하지 않을 수 있습니다(중국어에서 확인). 그러면 두 오버레이에서 이 채널들은 계속 비어 있습니다. EVE 언어를 English로 바꾸고 캐릭터로 다시 로그인하세요. 이런 경우 번역 오버레이의 상태 줄에 안내가 표시됩니다.
- 채널: "로그에서 추가"로 최근 채팅 로그에 있는 채널 중에서 고르거나(각 항목에 그 채널에 있는 내 캐릭터 수가 표시됨), 채널 이름을 입력하고 Return 키를 누릅니다. 로그 폴더는 기능이 켜져 있을 때, 또는 "로그에서 추가" 메뉴에서 "새로 고침"을 클릭할 때만 읽습니다. 기능이 꺼져 있는 동안 메뉴에는 처음에 "새로 고침"만 표시됩니다(번역 페이지에서는 기본 채널도 표시됨). 채널은 최대 16개입니다. 개인 대화는 읽지 않으며 목록에도 표시하지 않습니다.
- 켜면 오버레이에 최근 30분 동안의 메시지가 채워집니다("보관 기간", 5–120분). 오래된 줄은 사라집니다.
- 위치: 점프 수는 활성 캐릭터가 있는 성계에서 셉니다. 앱은 게임 로그의 점프 및 언도킹 줄과, Local 채팅 로그의 성계 변경 메시지에서 위치를 가져옵니다. 둘 다 없으면 "내 위치"에서 해당 캐릭터의 성계 이름을 입력하고 Return 키를 누릅니다. 알 수 없는 이름이면 "이 성계를 찾을 수 없음"이 표시됩니다. 수동 위치는 다음 점프 때 바뀌며, 재시작해도 유지됩니다. 위치가 전혀 없는 캐릭터는 "기준 성계"에서 점프 수를 셉니다.
- "계산 상한"은 점프 수의 상한입니다(1–30, 기본값 15). "강조 범위"는 보고된 성계가 그 점프 수 이내일 때 메시지를 강조합니다(기본값 5, 0이면 끔). "원문 표시"는 보낸 사람과 메시지를 둘째 줄에 추가합니다.
- 성계와 함선 이름은 인터페이스 언어로 표시합니다.
- 파일럿 이름은 메시지에서 성계, 함선, 수를 인식하고 남은 부분이므로, 공백이 있는 이름이 이어지면 구분이 모호합니다. "온라인 이름 확인 (ESI)"가 켜져 있으면(기본값) 앱은 CCP의 ESI에 그 단어 중 어느 것이 실제 캐릭터 이름인지 물어 그 결과대로 나눕니다([개인정보 보호](#개인정보-보호) 참고). 일치는 그 이름의 캐릭터가 존재한다는 뜻일 뿐, 메시지가 가리키는 캐릭터라는 뜻은 아닙니다. 일치한 이름에는 오른쪽 클릭 메뉴의 "브라우저에서 열기"에 zKillboard 링크가 붙습니다. "이름 캐시 지우기"는 저장된 이름을 삭제합니다.

### 채팅 번역

번역 페이지에서 "번역 오버레이 표시"를 켜거나, 메뉴 막대 메뉴에서 "번역 오버레이 표시"를 선택합니다. 선택한 채널의 메시지 중 번역 언어가 아닌 메시지를 번역합니다.

1. 정찰 오버레이와 같은 방법으로 채널을 고릅니다. "로그에서 추가"에는 기본 제공 채널인 로컬, 코퍼레이션, 얼라이언스, 플릿도 표시됩니다.
2. "번역 언어"에서 언어를 고르거나 "인터페이스 언어와 같게"(기본값)를 고릅니다.
3. "서비스"를 고릅니다: DeepSeek(기본값), Claude (Anthropic), OpenAI, Qwen (DashScope), Kimi (Moonshot), Ollama 또는 "기타(OpenAI 호환)". "API 주소"와 "모델 이름"에는 프리셋 값이 표시되며, 입력하면 프리셋 대신 사용됩니다.
4. API 키를 붙여 넣고 "저장"을 클릭합니다. 키는 macOS 키체인에 저장되며 "키 삭제"로 지웁니다. Ollama는 키가 필요 없습니다.
5. "테스트"를 클릭하면 고정된 예문 하나를 번역합니다.

- 모델에는 활성 클라이언트의 캐릭터가 받은 메시지만 보냅니다. 같은 문장은 한 번만 번역하고 이후에는 캐시에서 가져옵니다. 성계와 함선만 있는 메시지는 보내지 않습니다. 번역 언어가 중국어, 일본어, 한국어, 러시아어이면 이미 그 언어로 된 메시지도 보내지 않습니다. 번역 언어가 영어, 독일어, 프랑스어, 스페인어이면 이런 메시지를 모두 모델에 보내고, 이미 번역 언어인지는 모델이 판단합니다. 성계, 성역, 함선 이름은 번역 언어의 공식 이름을 씁니다.
- 각 줄에는 EVE 시간, 채널(번역하는 채널이 둘 이상일 때만), 보낸 사람, 번역문이 표시됩니다. "원문도 표시"는 그 아래에 원문을 추가하고, "번역된 메시지만 표시"는 이미 번역 언어라서 건너뛴 메시지와, 모델이 번역 언어라고 판단한 메시지를 숨깁니다.
- 서비스가 키를 거부하거나 사용 한도를 다 쓰면 번역이 일시 중지되고 상태 줄에 이유가 표시됩니다. "지금 다시 시도"로 다시 시도합니다.
- 공개 주소는 `https`를 써야 합니다. `http`는 이 Mac이나 로컬 네트워크(예: Ollama의 `http://127.0.0.1:11434/v1`)에서만 쓸 수 있습니다.
- 요청에는 선택한 서비스의 본인 계정이 쓰이며 비용이 발생할 수 있습니다.
- 다른 서명으로 다시 빌드한 뒤에는 "테스트"나 "지금 다시 시도"를 클릭할 때 macOS가 키체인 항목을 읽도록 허용할지 물을 수 있습니다. 백그라운드에서 읽을 때는 이 확인 창을 띄우지 않고, 대신 상태 줄이 키를 다시 저장하라고 안내하도록 설계되어 있습니다. 실제로 다시 빌드한 뒤의 동작은 아직 직접 확인해야 합니다.

### 오버레이 제스처

정찰 오버레이와 번역 오버레이는 썸네일처럼 동작하는 별도의 패널입니다. 포커스를 가져가지 않고, 모든 Spaces에 표시되며, 앞에 있는 EVE 윈도우의 캐릭터만 보여 주고, 클라이언트를 전환하면 바로 내용이 바뀝니다. 클릭은 게임으로 전달되지 않습니다. 가장 새로운 메시지는 맨 아래에 있고 목록은 맨 아래에 머뭅니다. 위로 스크롤하면 목록이 새 메시지를 따라가지 않으며, 아래쪽에 "새 메시지 N개" 막대가 표시됩니다. 클릭하면 최신으로 돌아갑니다.

| 작업 | 제스처 |
| --- | --- |
| 목록 스크롤 | 스크롤 휠 또는 두 손가락 쓸기 |
| 이동 | 오른쪽 드래그 또는 Option+왼쪽 드래그 |
| 크기 조절 | 이동과 같은 제스처를 오버레이 가장자리에서 12포인트 이내에서 시작 |
| 자석 맞춤 일시 해제 | 드래그하는 동안 Shift를 누릅니다 |
| 메뉴 열기 | 오른쪽 클릭(누른 뒤 놓을 때까지 4포인트 미만으로 이동) |
| 최신으로 돌아가기 | "새 메시지 N개" 막대 클릭 |

오른쪽 클릭 메뉴에는 최신으로 스크롤, 이 줄 복사, 브라우저에서 열기(링크가 있는 줄에만), 목록 지우기, 레이아웃 잠금, 위치와 크기를 기본값으로 되돌리기, 이 오버레이 숨기기, 설정 열기…가 있습니다. "배경 불투명도"(20%–100%, 배경에만 적용되며 글자는 항상 불투명)와 "글자 크기"(10–24포인트)는 각 기능의 페이지에 있습니다. "레이아웃 잠금"과 "EVE가 앞에 있지 않으면 썸네일 가리기"는 오버레이에도 적용됩니다. 모든 썸네일 가리기는 썸네일에만 적용됩니다.

### 메뉴 막대

메뉴 막대 아이콘은 앱 아이콘과 같으며, 팔각형 안의 분자 모양입니다. 메뉴에는 모든 썸네일 보기/가리기, 프로필 전환, 모든 클라이언트 최소화, 단축키를 EVE 안에서만 사용, 정찰 오버레이 표시, 번역 오버레이 표시, 업데이트 확인…, 문제 신고…, 설정, 종료가 있습니다. 업데이트가 있거나 이전 실행이 예기치 않게 종료되었으면 아이콘에 점이 표시되고, 메뉴 맨 위에 해당 항목이 추가됩니다. 권한이 없으면 메뉴에 이에 관한 항목이 하나 더 표시됩니다. 시스템의 화면 기록 표시기에서 클라이언트 캡처를 중지하면 메뉴에 "캡처 재개" 항목이 추가됩니다.

EVE-O Preview는 Dock에도 아이콘을 표시하며, 클릭하면 설정 창이 열립니다. 메뉴 막대 아이콘만 남기려면 설정 > 일반에서 "Dock에 아이콘 표시"를 끄십시오.

### 업데이트

EVE-O Preview는 실행할 때와 하루에 한 번 GitHub에서 새 릴리스를 확인합니다. 이 기능을 끄려면 설정 > 일반 > 업데이트에서 "자동으로 업데이트 확인"을 해제하십시오. 해제한 뒤에도 메뉴 막대 메뉴의 "업데이트 확인…"으로 필요할 때 직접 확인할 수 있습니다.

새 버전이 있으면 윈도우가 열려 UI 언어로 된 릴리스 노트(번역이 없으면 영어)를 보여 주고, "업데이트 설치", "이 버전 건너뛰기", "나중에"를 제공합니다. EVE 클라이언트가 앞에 있는 동안에는 다른 곳으로 전환할 때까지 윈도우가 기다리며, 스스로 키보드 포커스를 가져가지 않습니다. 메뉴 막대 아이콘의 점은 업데이트가 대기 중임을 나타냅니다. "이 버전 건너뛰기"는 해당 버전의 자동 알림만 멈추며, "업데이트 확인…"을 선택하면 그 버전이 계속 표시됩니다.

"업데이트 설치"는 dmg를 다운로드하고, `SHA256SUMS.txt`와 대조하여 확인하고, 새 앱이 실행 중인 앱과 같은 인증서로 서명되었는지 검증한 다음, 앱을 교체하고 다시 실행합니다. 어느 단계에서든 실패하면 설치된 앱은 바뀌지 않습니다. "자동으로 업데이트 설치"는 기본으로 켜져 있습니다. 업데이트를 백그라운드에서 다운로드하고, EVE 클라이언트가 약 1분 동안 실행되지 않고 EVE-O Preview 창도 열려 있지 않으면 설치한 뒤 앱을 다시 실행합니다. 그렇지 않으면 EVE-O Preview를 종료하거나 메뉴 막대 메뉴에서 "다시 실행하여 X.Y.Z 버전으로 업데이트"를 선택할 때 설치합니다. EVE 클라이언트가 실행 중일 때 앱이 스스로 다시 실행되는 일은 없습니다. 먼저 창에서 확인받으려면 설정 > 일반 > 업데이트에서 끄십시오.

일부 빌드는 설치하지 않고 이유와 "릴리스 페이지 열기" 버튼만 표시합니다. ad-hoc 서명이나 로컬에서 서명한 빌드, 디스크 이미지에서 실행하거나 macOS가 임시 위치로 옮겨(translocation) 실행한 앱, 쓰기 권한이 없는 폴더에 있는 앱, APFS가 아닌 볼륨(HFS+, exFAT, FAT 형식의 외장 디스크 등)에 있는 앱이 이에 해당합니다.

### 문제 신고

메뉴 막대 메뉴나 일반 페이지에서 "문제 신고…"를 선택하거나, EVE-O Preview가 예기치 않게 종료된 뒤 나타나는 안내에 응답합니다. 윈도우에는 보고서에 들어갈 모든 파일이 나열되고, 민감한 정보를 가린 뒤의 내용이 표시됩니다. 환경 요약, 이름을 뺀 설정 요약, 앱 로그(최대 2 MiB), 최대 3개의 macOS 충돌 보고서가 들어갑니다. "보고서만 만들기" 또는 "보고서 만들고 GitHub 열기"를 클릭하기 전에는 아무것도 만들어지지 않습니다. zip은 `~/Library/Application Support/EVE-O Preview/Reports/`에 저장되고(최신 3개를 보관) Finder에 표시됩니다. "보고서 만들고 GitHub 열기"는 브라우저에서 미리 채워진 이슈도 엽니다. zip은 직접 첨부해야 하며, 앱은 아무것도 업로드하지 않습니다.

macOS 사용자 이름, 전체 이름, 홈 폴더 경로, 컴퓨터 이름은 `[user]`와 `[host]`로 바뀝니다. EVE 캐릭터 이름은 `[character-1]`, `[character-2]` 등으로 바뀌고, 충돌 보고서의 기기 식별자는 `[redacted]`로 바뀝니다. 앱이 알고 있는 이름만 바뀝니다. 설정에 나온 적도 없고 실행 중인 클라이언트로 나타난 적도 없는 캐릭터의 이름은 바뀌지 않습니다. 이름이 흔한 단어이면 로그의 다른 곳에 있는 같은 단어도 바뀝니다. 보고서를 만들기 전에 모든 파일을 읽어 볼 수 있으며, 포함하고 싶지 않은 파일은 선택을 해제할 수 있습니다.

앱은 `~/Library/Logs/EVE-O Preview/`에 1 MiB짜리 로그 파일을 최대 5개 보관합니다. 캐릭터 이름과 윈도우 제목은 `<private>`로 기록됩니다. 일반 페이지에서 "상세 로그"를 켜면 디버그 줄도 기록되며, "Finder에서 로그 보기"는 해당 폴더를 엽니다. 충돌 후 안내가 나타나지 않으면 `~/Library/Logs/DiagnosticReports/EVEOPreview-<date>.ips`를 직접 이슈에 첨부하십시오.

## 개인정보 보호

앱은 업데이트를 위해 GitHub에 연결하며, 이 목록 뒤에 설명하는 선택 기능을 켜지 않는 한 다른 연결은 하지 않습니다.

- 업데이트를 확인할 때 `api.github.com/repos/deletexiumu/eve-o-preview/releases/latest`를 요청합니다. "자동으로 업데이트 확인"이 켜져 있으면 실행할 때와 하루에 한 번 요청하며, "업데이트 확인…"을 선택할 때마다 요청합니다.
- 새 버전을 안내할 때는 건너뛴 버전의 변경 내용을 보여 주기 위해 같은 헤더로 릴리스 목록 `api.github.com/repos/deletexiumu/eve-o-preview/releases`를 한 번 요청합니다.
- 업데이트를 설치할 때 릴리스에서 `SHA256SUMS.txt`와 dmg를 다운로드합니다.

요청에는 `User-Agent` 헤더에 담긴 앱 버전, 고정된 `Accept-Language: en`, 캐시 태그만 들어 있습니다. 캐릭터 이름, 설정, 로그, 하드웨어 정보, 시스템 버전, 식별자는 전송하지 않으며 쿠키도 사용하지 않습니다. GitHub는 사용자의 IP 주소와 요청 시각을 알 수 있습니다. 원격 측정이나 충돌 정보 자동 업로드는 없습니다. "문제 신고…"는 Mac에 zip을 만들고 웹 페이지를 열 뿐이며, 제출할지는 사용자가 결정합니다.

정찰 오버레이와 번역 오버레이는 채팅 로그와 게임 로그를 읽기만 하고 쓰지 않으며, 개인 대화는 읽지 않습니다. 다음 두 선택 기능은 다른 서비스에 연결합니다.

- 파일럿 이름 확인: 정찰 오버레이를 켜면 "온라인 이름 확인 (ESI)"는 기본적으로 켜져 있습니다. 활성 캐릭터가 받은 정찰 메시지에 두 단어 이상인 파일럿 이름이 이어져 있으면, 앱은 그 단어들을 단독으로, 그리고 최대 세 단어의 조합으로 CCP의 ESI(`esi.evetech.net/universe/ids`)에 보냅니다. 보낸 사람, 채널, 메시지의 나머지는 보내지 않습니다. 내 캐릭터 이름은 누군가 정찰 메시지에 적었을 때만 포함됩니다. 한 단어로만 따로 나오는 이름은 조회하지 않습니다. CCP는 사용자의 IP 주소와, 앱 버전과 프로젝트 URL이 담긴 `User-Agent` 헤더를 볼 수 있습니다. 이 요청을 멈추려면 정찰 페이지에서 이 설정을 끕니다. 앱 자체는 zKillboard에 연결하지 않습니다. "브라우저에서 열기"는 캐릭터의 zKillboard 페이지를 브라우저에서 열 뿐이며, 주소에는 캐릭터 ID만 들어갑니다.
- 채팅 번역(기본값은 꺼짐): 번역 채널에서 활성 클라이언트의 캐릭터가 받은 메시지 본문을, 거기에 나오는 성계와 함선의 공식 이름과 함께 번역 페이지에서 고른 모델 서비스로 보냅니다. 보낸 사람 이름과 채널 이름은 보내지 않습니다. "테스트"는 고정된 예문 하나를 보냅니다. API 키는 macOS 키체인에만, 서비스 `io.github.deletexiumu.eveopreview-macos.translation` 항목(모델 서비스마다 하나)으로 저장되며 그 모델 서비스에만 보냅니다. 설정 파일, 로그, 문제 보고서에는 들어가지 않습니다. 공개 주소는 `https`를 써야 하며, `http`는 이 Mac이나 로컬 네트워크(예: Ollama)에서만 쓸 수 있습니다. 서비스가 텍스트를 어떻게 처리하는지는 그 서비스의 약관을 따릅니다.

문제 보고서에는 이 기능들의 설정이 숫자와 켬/끔(채널 수, 선택한 서비스 등)으로만 들어가며, 채널 이름, 성계 이름, API 주소, 모델 이름, 파일럿 이름, 채팅 본문, 키는 들어가지 않습니다.

앱은 다음 위치에 데이터를 저장합니다. 완전히 제거하려면 앱과 함께 이 위치들과 `~/Library/Application Support/EVE-O Preview/config.json`을 삭제하십시오.

| 위치 | 내용 |
| --- | --- |
| `~/Library/Logs/EVE-O Preview/` | 앱 로그, 최대 약 5 MiB |
| `~/Library/Application Support/EVE-O Preview/session.json`, `state.json` | 세션 마커; 업데이트 및 진단 기록; 정찰의 수동 위치 |
| `~/Library/Application Support/EVE-O Preview/Reports/` | 직접 만든 문제 보고서 zip, 민감한 정보를 가린 상태(최신 3개) |
| `~/Library/Caches/io.github.deletexiumu.eveopreview-macos/Updates/` | 다운로드한 업데이트 파일, 설치 후 삭제됨 |
| `~/Library/Application Support/EVE-O Preview/pilot-names.json` | ESI에서 일치한 파일럿 이름과 캐릭터 ID(게임의 공개 데이터), 30일 동안 보관. 본인만 읽고 쓸 수 있으며(0600) 문제 보고서에 들어가지 않음. 정찰 페이지의 "이름 캐시 지우기"로 비움. 일치하지 않은 이름은 메모리에 6시간만 보관 |
| `~/Library/Application Support/EVE-O Preview/translation-cache.json` | 메시지 원문과 번역문, 보낸 사람과 채널 이름은 없음. 본인만 읽고 쓸 수 있으며(0600) 문제 보고서에 들어가지 않음. 번역 페이지의 "캐시 지우기"로 비움 |
| 서비스가 `io.github.deletexiumu.eveopreview-macos.translation`인 키체인 항목 | 번역용 API 키, 모델 서비스마다 하나. 번역 페이지의 "키 삭제"로 현재 모델 서비스의 항목을 삭제 |

## 설정 파일

설정은 `~/Library/Application Support/EVE-O Preview/config.json`에 저장됩니다. 모든 프로필이 파일 하나에 들어 있습니다.

- 변경 사항은 변경 후 0.5초 뒤에 자동으로 저장되며, 종료할 때 한 번 더 저장됩니다.
- 파일이 손상되었으면 `config.corrupt-<date-time>.json`으로 이름을 바꾸고 기본 설정을 사용합니다.
- 파일이 더 새로운 버전에서 만들어진 것이면, 앱은 기본 설정으로 실행되고 해당 세션 동안 디스크에 쓰지 않으며 파일을 덮어쓰지 않습니다.

프로필 페이지에 "Finder에서 보기" 버튼이 있습니다.

## 이식하지 않은 원본 프로젝트 기능

| 원본 프로젝트 기능 | 이유 |
| --- | --- |
| 프레임 속도 제한 및 선택적 음소거(Robin 인젝션) | 원본 프로젝트는 Windows 프로세스에 DLL을 주입합니다. macOS에는 이에 해당하는 공개 메커니즘이 없습니다 |
| CPU 선호도 | Windows CPU Sets에 의존합니다. Apple Silicon에는 프로세스를 특정 코어에 고정하는 공개 API가 없습니다 |
| 전투 로그 Augments: 피해량 수치, DPS, 수리량, 시스템 오버레이, FC 정적 데이터 | "미리 보기와 전환" 범위를 벗어나는 별도의 큰 하위 시스템입니다. "공격받으면 깜박이기"만 이식했습니다 |
| 테마, 레거시 UI, 사용자 지정 오른쪽 클릭 메뉴 스타일 | macOS 버전은 시스템 모양을 따릅니다 |

| 저수준 키보드 후크 | 키보드 단축키는 Carbon 전역 단축키를 사용합니다. 마우스 이벤트 탭은 마우스 버튼이 할당된 경우에만 생성됩니다 |

드래그 앤 드롭 도킹을 지원하는 영역, 다중 선택과 그룹 이동, 실행 취소, 자석 맞춤 안내선, Windows 설정 가져오기, 로그인 시 실행은 v1 이후에 계획되어 있습니다.

## 면책 조항

이 도구는 윈도우 포커스만 전환합니다. 여러 클라이언트에 입력을 동시에 보내지 않으며 게임 메모리를 읽거나 수정하지 않습니다. 이는 원본 프로젝트와 같은 경계입니다. 정찰 오버레이와 번역 오버레이는 클라이언트가 기록하는 로그 파일을 읽기만 합니다. 사용하기 전에 EVE Online 최종 사용자 라이선스 계약을 읽으십시오.

앱은 업데이트를 확인하고 다운로드하기 위해 GitHub에 연결합니다. CCP의 ESI와 번역 서비스에는 해당 선택 기능을 켰을 때만 연결하며, [개인정보 보호](#개인정보-보호)에 적힌 내용만 보냅니다.

EVE Online 및 관련 로고는 CCP ehf.의 상표입니다. 이 프로젝트는 CCP와 관련이 없으며 CCP의 승인을 받지 않았습니다.

앱 아이콘은 원본 프로젝트 EveOPlus/eve-o-preview(GPL-3.0)의 분자 아이콘을 재사용합니다. 배경은 `macos/scripts/make-app-icon.py`로 그렸으며 CCP 상표나 게임 아트를 포함하지 않습니다.
