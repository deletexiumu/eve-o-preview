# EVE-O Preview for macOS & Windows

[English](README.md) | [简体中文](README.zh-CN.md) | [日本語](README.ja.md) | [한국어](README.ko.md) | **Русский** | [Français](README.fr.md) | [Deutsch](README.de.md) | [Español](README.es.md)

Этот перевод выполнен машинным способом; если он расходится с [английским README](README.md), верным считается английский вариант.

EVE-O Preview показывает живую миниатюру каждого запущенного клиента EVE Online. Щелкните миниатюру или нажмите глобальную горячую клавишу, чтобы переключиться на этот клиент.

В этом репозитории два нативных приложения: для macOS на Swift и для Windows на Rust. Формат конфигурации, тексты интерфейса и тестовые сценарии в `shared/` у них общие, а работают они через API своей платформы.

Оба приложения заново реализуют возможности [EveOPlus/eve-o-preview](https://github.com/EveOPlus/eve-o-preview) (Windows, GPL-3.0). Они не переносят код исходного проекта на C#, а их интерфейс и формат конфигурации отличаются от исходного проекта.
Приложение распространяется по лицензии GNU General Public License версии 3 или любой более поздней версии (GPL-3.0-or-later), что соответствует идентификаторам SPDX в исходных файлах; исходный проект распространяется по лицензии GPL-3.0. Полный текст лицензии — в файле [LICENSE](LICENSE).

Этот репозиторий изначально был форком EveOPlus/eve-o-preview на GitHub и с версии 1.0 перенесён в отдельный репозиторий. Это независимый проект: у него нет общего кода с исходным EveOPlus/eve-o-preview, и авторы исходного проекта его не сопровождают.

## Windows

EVE-O Preview for Windows 1.0 вышла 2026-11-24. Возможности те же, что у версии для macOS: живые миниатюры DWM, переключение и горячие клавиши (включая кнопки мыши), расположение, правила видимости, боевые оповещения, оверлеи разведки и перевода чата, профили, обновления с проверкой подписи и сообщения о проблемах. Отличия от версии для macOS:

- **Частота кадров игры** (с 1.1, по умолчанию выключено): группа «Частота кадров игры» на странице «Общие» через видеодрайвер ограничивает все клиенты EVE одной частотой кадров (по умолчанию 60), и при игре в несколько окон переключение между клиентами становится плавнее. Клиенты игры не затрагиваются. Для NVIDIA задаётся «Максимальная частота кадров» для exefile.exe, для Intel — ограничение частоты кадров для exefile.exe; драйвер AMD умеет ограничивать только все игры на компьютере сразу. При выключении восстанавливается прежняя настройка драйвера. Поддержка AMD и Intel ещё не проверена на реальном оборудовании.
- **Запускать при входе в Windows** на странице «Общие».
- Значок в области уведомлений вместо значка в строке меню: щелчок левой кнопкой открывает настройки, правой — меню.
- Ключи API хранятся в диспетчере учётных данных Windows вместо связки ключей macOS.

### Установка в Windows

Нужна 64‑битная Windows 10 22H2 или Windows 11.

1. Скачайте `EVE-O-Preview-<версия>-windows-x64.zip` со страницы [Releases](https://github.com/deletexiumu/eve-o-preview/releases). Выпуски для Windows помечены тегом `win-v<версия>`; выпуск с пометкой «Latest» — это версия для macOS.
2. Распакуйте папку туда, где у вас есть права на запись, например в «Документы» или `D:\Games`. Не используйте «Program Files»: обновления заменяют exe на месте.
3. Запустите `EVE-O Preview.exe`. У exe пока нет цифровой подписи, поэтому при первом запуске Windows SmartScreen может показать предупреждение: выберите «Подробнее», затем «Выполнить в любом случае».

Настройки хранятся в `%APPDATA%\EVE-O Preview\config.json`, журналы — в `%LOCALAPPDATA%\EVE-O Preview\logs\`. Настройки оригинального EVE-O Preview не импортируются. Чтобы удалить приложение, выйдите из него через меню в области уведомлений, выключите «Запускать при входе в Windows», если включали, затем удалите папку приложения и две папки выше. Сборка из исходного кода описана в [windows/README.md](windows/README.md).

Остальная часть документа описывает версию для macOS.

## Возможности

- Обнаружение клиентов: миниатюры обновляются автоматически, когда клиент запускается, завершается или меняет название после входа.
- Живые миниатюры: один поток ScreenCaptureKit на каждый клиент, размер и частота кадров настраиваются.
- Панели миниатюр: никогда не забирают фокус, отображаются на всех рабочих столах и при желании могут оставаться поверх других окон. По умолчанию у них светло-серая рамка толщиной 2 пт, чтобы соседние миниатюры было легко различить; цвет и толщину можно изменить, а рамку — отключить.
- Переключение: щелчок левой кнопкой по миниатюре переключает на ее клиент; Ctrl+щелчок сворачивает его. В контекстном меню есть пункты «Свернуть», «Свернуть все», «Пропускать при переключении», «Скрыть эту миниатюру» и «Вернуть размер по умолчанию».
- Наложения: имя персонажа в заголовке, рамка подсветки активного клиента (цвет настраивается для каждого персонажа; пока подсветка видна, она заменяет светло-серую рамку) и отметка пропуска при переключении.
- «Увеличение при наведении» (9 точек привязки) и непрозрачность.
- Видимость: скрытие миниатюры активного клиента; скрытие, когда EVE не на переднем плане (с задержкой); скрытие для отдельных персонажей; скрытие всех миниатюр.
- Расположение: перетаскивание для перемещения и изменения размера, прилипание к другим миниатюрам и краям экрана, по желанию — закрепление расположения. Положение и размер сохраняются для каждого персонажа; клиенты на экране входа используют отдельную начальную позицию.
- Группы переключения: горячие клавиши «вперед» и «назад», пропуск на текущий сеанс; горячие клавиши персонажей; горячая клавиша для перебора клиентов на экране входа; горячие клавиши для скрытия всех миниатюр и сворачивания всех клиентов. Для горячих клавиш можно использовать среднюю и боковые кнопки мыши, и каждая горячая клавиша может действовать везде или только в EVE.
- Боевые оповещения (по умолчанию выключены): приложение читает игровые журналы и заставляет миниатюру персонажа мигать, когда этого персонажа атакуют.
- Оверлей разведки (по умолчанию выключен): читает журналы чата выбранных вами каналов разведки и показывает для персонажа в активном окне EVE, в каких системах замечены враги, в скольких прыжках они от вас, сколько их и на каких кораблях (см. [Оверлей разведки](#оверлей-разведки)).
- Оверлей перевода чата (по умолчанию выключен): переводит на ваш язык сообщения на других языках из выбранных каналов с помощью выбранного вами сервиса моделей и вашего собственного ключа API (см. [Перевод чата](#перевод-чата)).
- Профили: создание, дублирование, переименование, удаление и переключение.
- Обновления: приложение проверяет новые релизы на GitHub и устанавливает их прямо из приложения после проверки загруженного файла и его подписи кода (см. [Обновления](#обновления)).
- Отчёты о проблемах: приложение собирает обезличенный zip-архив с диагностикой и открывает заранее заполненный issue на GitHub; после неожиданного завершения при следующем запуске приложение предлагает сообщить о нём (см. [Сообщить о проблеме](#сообщить-о-проблеме)).
- Значок в строке меню вместо значка в области уведомлений Windows.
- Окно настроек из 10 страниц: «Клиенты», «Миниатюры», «Переключение», «Оповещения», «Разведка», «Перевод», «Профили», «Общие», «Разрешения» и «О программе».
- Языки интерфейса: английский (по умолчанию), китайский, русский, японский, корейский, французский, немецкий и испанский. Язык переключается на странице «Общие», можно также выбрать «Как в системе»; изменение вступает в силу сразу. Русский, японский, корейский, французский, немецкий и испанский переводы выполнены машинным способом; исправления приветствуются.

## Требования

- macOS 14 или новее, на Apple Silicon или Intel. Релизный dmg содержит универсальный двоичный файл.
- Клиенты EVE лучше запускать в оконном режиме. Начиная с 1.1.1 поддерживаются и клиенты в полноэкранном режиме macOS (при включённом параметре «Миниатюры поверх других окон» миниатюры отображаются поверх полноэкранного изображения), но каждый из них находится на отдельном рабочем столе, поэтому при переключении проигрывается анимация смены рабочего стола.

## Установка

### Загрузка релиза

1. Скачайте `EVE-O-Preview-<version>.dmg` со страницы [Releases](https://github.com/deletexiumu/eve-o-preview/releases).
2. Откройте dmg и перетащите `EVE-O Preview.app` в папку «Программы».
3. Откройте приложение. Его значок появится в строке меню, а при первом запуске окно настроек откроется на странице «Разрешения».

Релизные сборки подписаны собственным самоподписанным сертификатом проекта и не нотаризованы, потому что у проекта нет Apple Developer ID. При первом запуске macOS блокирует приложение с сообщением о том, что не удается проверить разработчика. Чтобы открыть приложение:

1. Откройте «Системные настройки» > «Конфиденциальность и безопасность».
2. Прокрутите вниз до сообщения об EVE-O Preview, нажмите «Все равно открыть» и подтвердите.

Если macOS сообщает, что приложение «повреждено, и его не удается открыть», или вместо описанных выше шагов удалите атрибут карантина в Терминале:

```sh
xattr -dr com.apple.quarantine "/Applications/EVE-O Preview.app"
```

**Примечание:** все релизы подписаны одним и тем же сертификатом, поэтому при обновлении macOS сохраняет разрешения «Запись экрана» и «Универсальный доступ». Если после обновления разрешения перестали работать, сбросьте их командами `tccutil` в конце раздела [Разрешения](#разрешения) и выдайте снова.

Приложение обновляется само: оно проверяет новые версии на GitHub и устанавливает их прямо из приложения (см. [Обновления](#обновления)).

Каждый релиз также содержит исходный код в виде `.tar.gz` и `.zip` и файл `SHA256SUMS.txt`. Чтобы проверить загруженные файлы, выполните `shasum -a 256 --ignore-missing -c SHA256SUMS.txt` в папке загрузки.

## Разрешения

Приложение использует перечисленные ниже системные разрешения; все они выдаются в разделе «Системные настройки» > «Конфиденциальность и безопасность». Страница «Разрешения» в окне настроек показывает их состояние, кнопки запроса и ссылки на Системные настройки.

| Разрешение | Для чего | Без него |
| --- | --- | --- |
| Запись экрана | Захват окон клиентов и чтение заголовков окон | Миниатюры показывают заглушку; если нет и Универсального доступа, заголовки прочитать нельзя, и клиенты отображаются как `EVE (PID)` |
| Универсальный доступ | Разворачивание, вывод на передний план и сворачивание окон клиентов, чтение заголовков окон, перехват горячих клавиш мыши | Можно активировать только процесс клиента, поэтому свернутые окна не разворачиваются; пункты «Свернуть» и «Свернуть все» недоступны; горячие клавиши мыши не работают, клавиатурные продолжают работать |
| Папка «Документы» | Боевые оповещения читают `~/Documents/EVE/logs/Gamelogs`; оверлеи разведки и перевода читают `~/Documents/EVE/logs/Chatlogs`, а оверлей разведки также читает игровые журналы, чтобы определить ваше местоположение | Запрашивается, только когда включена одна из этих функций или нажата кнопка «Обновить» в меню «Добавить из журналов»; при отказе страница этой функции показывает причину, остальные функции не затрагиваются |
| Локальная сеть (macOS 15 и новее) | Подключение к сервису перевода на другом компьютере в локальной сети, например к Ollama | Запрашивается, только если сервис перевода работает на другом компьютере в локальной сети, но не для этого Mac и не для публичных сервисов; чтобы запрос появился заранее, нажмите «Проверить» на странице «Перевод». При отказе запросы к этому компьютеру завершаются сетевой ошибкой. На странице «Разрешения» не показывается |

После выдачи разрешения «Запись экрана» приложение обычно нужно перезапустить, чтобы разрешение вступило в силу; на странице «Разрешения» есть кнопка «Перезапустить». Универсальный доступ начинает действовать сразу.

Если записи о разрешениях оказались в неправильном состоянии, выполните эти две команды и снова выдайте разрешения:

```sh
tccutil reset ScreenCapture io.github.deletexiumu.eveopreview-macos
tccutil reset Accessibility io.github.deletexiumu.eveopreview-macos
```

## Использование

### Жесты на миниатюрах

Нажатие левой кнопки мыши переключает сразу, не дожидаясь отпускания, поэтому для перемещения и изменения размера используется перетаскивание правой кнопкой или перетаскивание левой кнопкой с Option.

| Действие | Жест |
| --- | --- |
| Переключиться на клиент | Нажатие левой кнопки мыши |
| Свернуть клиент | Ctrl+нажатие левой кнопки мыши |
| Открыть меню | Щелчок правой кнопкой (смещение между нажатием и отпусканием меньше 4 пт) |
| Переместить | Перетаскивание правой кнопкой или Option+перетаскивание левой кнопкой |
| Изменить размер | Тот же жест, что и для перемещения, но начатый не дальше 12 пт от края миниатюры |
| Временно отключить прилипание | Удерживайте Shift при перетаскивании; при изменении размера Shift также сохраняет пропорции |

Когда включен параметр «Закрепить расположение», перемещение и изменение размера не работают; переключение, сворачивание и меню продолжают работать.

### Горячие клавиши

Горячие клавиши записываются на странице «Переключение» в окне настроек: нажмите кнопку, затем нажмите сочетание клавиш или кнопку мыши. Esc отменяет запись, Delete очищает. Одному действию можно назначить несколько привязок.

- Группы переключения: у каждой группы есть горячие клавиши «вперед» и «назад», которые по порядку переключают между персонажами группы, находящимися в сети и не пропускаемыми, а после последнего возвращаются к первому.
- Горячие клавиши персонажей: переключают на клиент этого персонажа.
- Общие горячие клавиши: показать или скрыть все миниатюры, свернуть все клиенты и перебирать клиенты на экране входа.

Клавиатурные горячие клавиши должны включать Ctrl, Option или Command; F1–F20 и цифры цифрового блока можно использовать отдельно. Системные сочетания, такие как Cmd+Tab, Cmd+Space и Cmd+Q, отклоняются. Если с горячей клавишей есть проблема, окно настроек показывает причину рядом с ней.

Горячие клавиши мыши:

- Среднюю и боковые кнопки можно записать (в конфигурации они записываются как `Mouse3`–`Mouse32`), при желании с модификаторами, например `ctrl+Mouse4`. Левую и правую кнопки назначить нельзя.
- Когда горячая клавиша срабатывает, этот щелчок (нажатие, перетаскивание и отпускание) не передается приложению на переднем плане, поэтому игровое действие, назначенное на ту же кнопку, не выполняется.
- Горячим клавишам мыши нужно разрешение «Универсальный доступ».

Область действия:

- Каждая горячая клавиша может действовать «Везде» или «Только в EVE»; в конфигурации это записывается суффиксом `@global` или `@game`. Горячая клавиша без суффикса использует область действия по умолчанию из профиля.
- Горячая клавиша с областью «Только в EVE» работает, только пока клиент EVE на переднем плане. В других приложениях нажатие передается этому приложению как обычно.
- Новые горячие клавиши мыши по умолчанию получают область «Только в EVE», чтобы боковые кнопки не перехватывались во всех приложениях.
- Пункт «Горячие клавиши только в EVE» в меню строки меню переключает область действия по умолчанию.

### Боевые оповещения

Включите их на странице «Оповещения» в окне настроек. После этого приложение читает игровые журналы, которые клиенты пишут в `~/Documents/EVE/logs/Gamelogs`, сопоставляет каждый журнал с персонажем по слушателю, указанному в заголовке журнала, и при атаке на персонажа 3 секунды мигает рамкой и изображением его миниатюры.

- В клиенте EVE должна быть включена запись игровых журналов (по умолчанию она включена).
- Промахи по умолчанию тоже вызывают оповещение; это можно отключить. Минимальный урон, цвет и длительность мигания настраиваются.
- Если включен параметр «Скрывать миниатюры, когда EVE не на переднем плане», миниатюра атакованного персонажа временно показывается.
- Если в Системных настройках включен параметр «Уменьшить движение», мигание заменяется постоянной подсветкой.
- Приложение только читает журналы. Оно никогда не записывает и не изменяет их и не отправляет в игру никакого ввода.
- В первый раз macOS запросит доступ к папке «Документы». Если ваши журналы находятся в другом месте, выберите папку на странице «Оповещения».
- Формат журналов китайского клиента проверен на реальных журналах. Строки урона на японском и русском проверены на журналах реальных клиентов (записанных образцах исходного проекта); их строки промахов выведены только из шаблонов. Английский, немецкий, французский, испанский и корейский форматы выведены из шаблонов исходного проекта и на реальных журналах не проверялись.

### Оверлей разведки

Включите его параметром «Показывать оверлей разведки» на странице «Разведка» окна настроек или пунктом «Показать оверлей разведки» в меню строки меню. После этого приложение читает журналы чата, которые клиенты пишут в `~/Documents/EVE/logs/Chatlogs`, рядом с папкой игровых журналов, выбранной на странице «Оповещения». Каждая строка оверлея — одно сообщение из ваших каналов разведки: его возраст, каждая система с уровнем безопасности и расстоянием в прыжках от вашего местоположения, число врагов, корабли и имена пилотов.

- В клиенте EVE должна быть включена запись чата в файл.
- Если язык клиента не английский, EVE для Mac может не записывать журналы Local, Corp и Alliance (замечено с китайским), и эти каналы в обоих оверлеях остаются пустыми. Переключите язык EVE на English и войдите персонажем заново; в этом случае строка состояния оверлея перевода сообщит об этом.
- Каналы: выберите «Добавить из журналов», чтобы выбрать канал из недавних журналов чата (у каждого указано, сколько ваших персонажей в нём), или введите название канала и нажмите Return. Папка журналов читается, только когда функция включена или когда вы нажимаете «Обновить» в меню «Добавить из журналов»; пока функция выключена, в меню сначала есть только «Обновить» (на странице «Перевод» — ещё и встроенные каналы). Не больше 16 каналов. Личные разговоры никогда не читаются и не попадают в список.
- При включении оверлей заполняется сообщениями за последние 30 минут («Хранить последние», 5–120 минут); более старые строки исчезают.
- Местоположение: прыжки считаются от системы, в которой находится активный персонаж. Приложение берёт её из строк о прыжках и выходе со станции в игровых журналах и из сообщений о смене системы в журнале чата Local. Если нет ни того, ни другого, введите название системы для этого персонажа в разделе «Моё местоположение» и нажмите Return; для неизвестного названия появится «Система не найдена». Следующий прыжок заменяет местоположение, заданное вручную, а заданное вручную местоположение сохраняется после перезапуска. Для персонажа без местоположения прыжки считаются от системы в поле «Опорная система».
- «Считать до» ограничивает число прыжков (1–30, по умолчанию 15). «Подсвечивать в пределах» подсвечивает сообщение, когда упомянутая система находится на таком числе прыжков или ближе (по умолчанию 5; 0 отключает подсветку). «Показывать исходный текст» добавляет второй строкой отправителя и сообщение.
- Названия систем и кораблей показываются на языке интерфейса.
- Имена пилотов — это то, что остаётся от сообщения после распознавания систем, кораблей и чисел, поэтому идущие подряд имена с пробелами неоднозначны. При включённой «Онлайн-проверка имён (ESI)» (по умолчанию) приложение спрашивает у ESI компании CCP, какие из этих слов — настоящие имена персонажей, и делит их соответственно (см. [Конфиденциальность](#конфиденциальность)). Совпадение означает лишь, что персонаж с таким именем существует, а не что имеется в виду именно он. У найденного имени в контекстном меню есть ссылка на zKillboard в пункте «Открыть в браузере». «Очистить кэш имён» удаляет сохранённые имена.

### Перевод чата

Включите его параметром «Показывать оверлей перевода» на странице «Перевод» или пунктом «Показать оверлей перевода» в меню строки меню. Он переводит сообщения в выбранных каналах, которые ещё не на целевом языке.

1. Выберите каналы так же, как для оверлея разведки; «Добавить из журналов» дополнительно показывает встроенные каналы «Локал», «Корпорация», «Альянс» и «Флот».
2. В поле «Переводить на» выберите язык или «Как язык интерфейса» (по умолчанию).
3. Выберите «Сервис»: DeepSeek (по умолчанию), Claude (Anthropic), OpenAI, Qwen (DashScope), Kimi (Moonshot), Ollama или «Другой (совместимый с OpenAI)». В полях «Адрес API» и «Имя модели» показаны значения предустановки; введите свои, чтобы их заменить.
4. Вставьте ключ API и нажмите «Сохранить». Ключ хранится в связке ключей macOS; «Удалить ключ» удаляет его. Для Ollama ключ не нужен.
5. Нажмите «Проверить», чтобы перевести одну фиксированную тестовую фразу.

- Модели отправляются только сообщения, полученные персонажем активного клиента. Одна и та же фраза переводится один раз, затем берётся из кэша. Сообщения, где есть только системы и корабли, не отправляются. Если целевой язык — китайский, японский, корейский или русский, не отправляются и сообщения, уже написанные на этом языке. Если целевой язык — английский, немецкий, французский или испанский, все такие сообщения отправляются модели, и она сама решает, написаны ли они уже на целевом языке. Названия систем, регионов и кораблей даются в официальном написании на целевом языке.
- В каждой строке — время EVE, канал (только если переводится больше одного), отправитель и перевод. «Показывать и исходный текст» добавляет оригинал под переводом; «Показывать только переведённые сообщения» скрывает сообщения, пропущенные потому, что они уже на целевом языке, в том числе те, которые модель сочла написанными на нём.
- Если сервис отклоняет ключ или квота исчерпана, перевод приостанавливается, а строка состояния объясняет причину; «Повторить сейчас» пробует снова.
- Публичные адреса должны использовать `https`; `http` допускается только для этого Mac или локальной сети, например для Ollama по адресу `http://127.0.0.1:11434/v1`.
- Запросы идут от вашей учётной записи в выбранном сервисе и могут стоить денег.
- После пересборки с другой подписью macOS может запросить разрешение на чтение элемента связки ключей, когда вы нажимаете «Проверить» или «Повторить сейчас». Фоновые чтения никогда не показывают этот запрос; вместо этого строка состояния просит сохранить ключ заново.

### Жесты на оверлеях

Оверлеи разведки и перевода — отдельные панели, которые ведут себя как миниатюры: никогда не забирают фокус, отображаются на всех рабочих столах и показывают только персонажа активного окна EVE, сразу меняя содержимое при переключении клиента. Щелчки не проходят в игру. Новейшее сообщение внизу, и список остаётся внизу. Если прокрутить вверх, список перестаёт следовать за новыми сообщениями, а внизу появляется полоса «N новых сообщений»; щёлкните её, чтобы вернуться к последним.

| Действие | Жест |
| --- | --- |
| Прокрутить список | Колесо мыши или смахивание двумя пальцами |
| Переместить | Перетаскивание правой кнопкой или Option+перетаскивание левой кнопкой |
| Изменить размер | Тот же жест, что и для перемещения, но начатый не дальше 12 пт от края оверлея |
| Временно отключить прилипание | Удерживайте Shift при перетаскивании |
| Открыть меню | Щелчок правой кнопкой (смещение между нажатием и отпусканием меньше 4 пт) |
| Вернуться к последним | Щелчок по полосе «N новых сообщений» |

В контекстном меню есть пункты «Прокрутить к последним», «Копировать эту строку», «Открыть в браузере» (только на строках со ссылками), «Очистить список», «Закрепить расположение», «Вернуть положение и размер по умолчанию», «Скрыть этот оверлей» и «Открыть настройки…». «Непрозрачность фона» (20–100%, только фон; текст остаётся непрозрачным) и «Размер шрифта» (10–24 пт) находятся на странице каждой функции. «Закрепить расположение» и «Скрывать миниатюры, когда EVE не на переднем плане» действуют и на оверлеи; «Скрыть все миниатюры» действует только на миниатюры.

### Строка меню

Значок в строке меню — молекула внутри восьмиугольника. В меню есть пункты «Показать все миниатюры» или «Скрыть все миниатюры», переключение профиля, «Свернуть все клиенты», «Горячие клавиши только в EVE», «Показать оверлей разведки», «Показать оверлей перевода», «Проверить наличие обновлений…», «Сообщить о проблеме…», «Настройки…» и «Завершить EVE-O Preview». Если доступно обновление или предыдущий запуск неожиданно завершился, на значке появляется точка, а вверху меню — соответствующий пункт. Если какого-либо разрешения не хватает, в меню появляется дополнительный пункт об этом. Если остановить захват клиента через системный индикатор записи, в меню появится пункт «Возобновить захват».

EVE-O Preview также показывает значок в Dock; щелчок по нему открывает окно настроек. Чтобы оставить только значок в строке меню, снимите флажок «Показывать значок в Dock» в разделе «Настройки» > «Общие».

### Обновления

EVE-O Preview проверяет наличие нового релиза на GitHub при запуске и раз в день. Чтобы отключить проверку, снимите флажок «Автоматически проверять наличие обновлений» в разделе «Настройки» > «Общие» > «Обновления»; пункт «Проверить наличие обновлений…» в меню строки меню по-прежнему проверяет обновления по запросу.

Когда доступна новая версия, окно показывает примечания к релизу на языке интерфейса (на английском, если перевода нет) и предлагает кнопки «Установить обновление», «Пропустить эту версию» и «Позже». Пока на переднем плане клиент EVE, окно ждёт, пока вы не переключитесь на другое приложение, и никогда само не забирает фокус клавиатуры; точка на значке в строке меню показывает, что обновление ожидает установки. «Пропустить эту версию» только отключает автоматические напоминания об этой версии; «Проверить наличие обновлений…» всё равно её покажет.

«Установить обновление» загружает dmg, сверяет его с `SHA256SUMS.txt`, проверяет, что новое приложение подписано тем же сертификатом, что и запущенное, затем заменяет приложение и перезапускает его. Если какой-либо шаг не удался, установленное приложение остаётся без изменений. Параметр «Автоматически устанавливать обновления» включён по умолчанию: обновление загружается в фоне, а затем устанавливается с перезапуском приложения, когда клиент EVE не запущен около минуты и окна EVE-O Preview закрыты. В остальных случаях оно устанавливается, когда вы завершаете EVE-O Preview или выбираете «Перезапустить и обновить до X.Y.Z» в меню строки меню. Пока запущен клиент EVE, приложение само не перезапускается. Если вы хотите, чтобы сначала появлялось окно с вопросом, выключите этот параметр в разделе «Настройки» > «Общие» > «Обновления».

Некоторые сборки вместо установки могут только показать причину и кнопку «Открыть страницу выпуска»: сборки с подписью ad-hoc или с локальной подписью, приложение, запущенное с образа диска или из временного места после транслокации, приложение в папке, в которую у вас нет прав на запись, и приложение на томе, отличном от APFS (например, на внешнем диске HFS+, exFAT или FAT).

### Сообщить о проблеме

Выберите «Сообщить о проблеме…» в меню строки меню или на странице «Общие» либо ответьте на запрос, который появляется после неожиданного завершения EVE-O Preview. Окно перечисляет все файлы, которые войдут в отчёт, и показывает их содержимое после обезличивания: сводку об окружении, сводку настроек без каких-либо имён, журнал приложения (до 2 МиБ) и до трёх отчётов о сбоях macOS. Пока вы не нажмёте «Только создать отчёт» или «Создать отчёт и открыть GitHub», ничего не создаётся. Zip-архив сохраняется в `~/Library/Application Support/EVE-O Preview/Reports/` (хранятся 3 последних), и Finder показывает его; «Создать отчёт и открыть GitHub» также открывает в браузере заранее заполненный issue. Zip-архив вы прикрепляете сами; приложение ничего не выгружает.

Имя пользователя macOS, полное имя, путь к домашней папке и имена компьютера заменяются на `[user]` и `[host]`. Имена персонажей EVE заменяются на `[character-1]`, `[character-2]` и так далее, а идентификаторы устройств в отчётах о сбоях — на `[redacted]`. Заменяются только имена, известные приложению: персонажи, которые ни разу не встречались в ваших настройках или как запущенный клиент, не заменяются. Если имя совпадает с распространённым словом, то же слово заменяется и в других местах журнала. Перед созданием отчёта можно прочитать каждый файл и снять флажок с любого файла, который вы не хотите включать.

Приложение хранит до 5 файлов журнала по 1 МиБ каждый в `~/Library/Logs/EVE-O Preview/`. Имена персонажей и заголовки окон записываются как `<private>`. Включите «Подробный журнал» на странице «Общие», чтобы также записывать отладочные строки; кнопка «Показать журналы в Finder» открывает эту папку. Если после сбоя запрос не появился, прикрепите к issue вручную файл `~/Library/Logs/DiagnosticReports/EVEOPreview-<date>.ips`.

## Конфиденциальность

Приложение подключается к GitHub ради обновлений и не устанавливает других подключений, если вы не включили одну из необязательных функций, описанных после этого списка:

- Проверка обновлений запрашивает `api.github.com/repos/deletexiumu/eve-o-preview/releases/latest` при запуске и раз в день, пока включён параметр «Автоматически проверять наличие обновлений», а также каждый раз, когда вы выбираете «Проверить наличие обновлений…».
- Когда приложение предлагает новую версию, оно один раз запрашивает список выпусков `api.github.com/repos/deletexiumu/eve-o-preview/releases` с теми же заголовками, чтобы показать изменения пропущенных версий.
- Установка обновления загружает `SHA256SUMS.txt` и dmg из релиза.

Запросы содержат только версию приложения в заголовке `User-Agent`, фиксированный `Accept-Language: en` и метку кэша; имена персонажей, настройки, журналы, сведения об оборудовании, версия системы и идентификаторы не отправляются, cookie не используются. GitHub видит ваш IP-адрес и время запроса. Телеметрии и автоматической выгрузки отчётов о сбоях нет: «Сообщить о проблеме…» только создаёт zip-архив на вашем Mac и открывает веб-страницу, а отправлять ли её, решаете вы.

Оверлеи разведки и перевода только читают журналы чата и игровые журналы; они никогда в них не пишут, а личные разговоры не читаются вовсе. Две необязательные функции подключаются к другим сервисам:

- Проверка имён пилотов: «Онлайн-проверка имён (ESI)» включена по умолчанию, как только вы включаете оверлей разведки. Когда сообщение разведки, полученное активным персонажем, содержит идущие подряд имена пилотов из двух и более слов, приложение отправляет эти слова — по отдельности и в сочетаниях до трёх — в ESI компании CCP по адресу `esi.evetech.net/universe/ids`. Отправитель, канал и остальной текст сообщения не отправляются; имена ваших персонажей попадают туда, только если кто-то написал их в сообщении разведки. Имя из одного слова, стоящее отдельно, никогда не проверяется. CCP видит ваш IP-адрес и заголовок `User-Agent` с версией приложения и адресом проекта. Чтобы прекратить эти запросы, выключите параметр на странице «Разведка». Само приложение никогда не обращается к zKillboard: «Открыть в браузере» открывает страницу персонажа на zKillboard в вашем браузере, и в адресе есть только ID персонажа.
- Перевод чата (по умолчанию выключен): текст сообщений, полученных персонажем активного клиента в каналах перевода, отправляется в сервис моделей, выбранный на странице «Перевод», вместе с официальными названиями упомянутых в них систем и кораблей. Имена отправителей и названия каналов не отправляются; «Проверить» отправляет одну фиксированную тестовую фразу. Ключ API хранится только в связке ключей macOS под службой `io.github.deletexiumu.eveopreview-macos.translation`, по одному элементу на сервис, и отправляется только этому сервису. Он никогда не попадает в файл конфигурации, журналы и отчёты о проблемах. Публичные адреса должны использовать `https`; `http` допускается только для этого Mac или локальной сети, например для Ollama. Что сервис делает с текстом, определяют его собственные условия.

Отчёты о проблемах содержат настройки этих функций в виде чисел и переключателей (например, число каналов и выбранный сервис), но не содержат названий каналов и систем, адресов API, имён моделей, имён пилотов, текста чата и ключей.

Приложение хранит данные в следующих местах. Для полного удаления удалите их вместе с приложением и `~/Library/Application Support/EVE-O Preview/config.json`:

| Расположение | Содержимое |
| --- | --- |
| `~/Library/Logs/EVE-O Preview/` | Журналы приложения, не более примерно 5 МиБ |
| `~/Library/Application Support/EVE-O Preview/session.json`, `state.json` | Метка сеанса; записи об обновлениях и диагностике; заданные вручную местоположения для разведки |
| `~/Library/Application Support/EVE-O Preview/Reports/` | Созданные вами zip-архивы отчётов о проблемах, обезличенные (3 последних) |
| `~/Library/Caches/io.github.deletexiumu.eveopreview-macos/Updates/` | Загруженные файлы обновлений; удаляются после установки |
| `~/Library/Application Support/EVE-O Preview/pilot-names.json` | Имена пилотов и ID персонажей, найденные через ESI (публичные игровые данные), хранятся 30 дней. Доступен только вам (0600) и никогда не попадает в отчёты о проблемах; «Очистить кэш имён» на странице «Разведка» очищает его. Имена без совпадения хранятся только в памяти, 6 часов |
| `~/Library/Application Support/EVE-O Preview/translation-cache.json` | Исходный и переведённый текст сообщений, без имён отправителей и названий каналов. Доступен только вам (0600) и никогда не попадает в отчёты о проблемах; «Очистить кэш» на странице «Перевод» очищает его |
| Элементы связки ключей со службой `io.github.deletexiumu.eveopreview-macos.translation` | Ваши ключи API для перевода, по одному на сервис; «Удалить ключ» на странице «Перевод» удаляет ключ текущего сервиса |

## Файл конфигурации

Конфигурация хранится в `~/Library/Application Support/EVE-O Preview/config.json`. Один файл содержит все профили.

- Изменения сохраняются автоматически через 0,5 секунды после внесения и еще раз при выходе.
- Если файл поврежден, он переименовывается в `config.corrupt-<date-time>.json`, а приложение использует конфигурацию по умолчанию.
- Если файл создан более новой версией, приложение работает с конфигурацией по умолчанию, ничего не записывает на диск в течение этого сеанса и не перезаписывает файл.

На странице «Профили» есть кнопка «Показать в Finder».

## Возможности исходного проекта, которые не перенесены

| Возможность исходного проекта | Причина |
| --- | --- |
| Ограничение частоты кадров и выборочное отключение звука (внедрение Robin) | Исходный проект внедряет DLL в процессы Windows; в macOS нет аналогичного публичного механизма. Версия для Windows вместо этого ограничивает частоту кадров через видеодрайвер (см. [Windows](#windows)) |
| Привязка к ядрам процессора | Опирается на CPU Sets в Windows; в Apple Silicon нет публичного API для привязки процесса к ядрам |
| Augments боевого журнала: числа урона, DPS, объем ремонта, оверлей системы, статические данные для FC | Большая отдельная подсистема за пределами задачи «предпросмотр и переключение»; перенесено только «мигание при атаке» |
| Темы, старый интерфейс, пользовательские стили контекстного меню | Версия для macOS следует системному оформлению |
| Режим совместимого захвата (`PrintWindow`) | ScreenCaptureKit — единственный способ захвата |
| Низкоуровневый перехват клавиатуры | Клавиатурные горячие клавиши используют глобальные горячие клавиши Carbon; перехват событий мыши создается, только если назначена кнопка мыши |

Области с закреплением перетаскиванием, множественный выбор и групповое перемещение, отмена действий, направляющие прилипания, импорт конфигураций из Windows и запуск при входе в систему запланированы на период после v1.

## Отказ от ответственности

Этот инструмент только переключает фокус окон. Он не транслирует ввод в несколько клиентов и не читает и не изменяет память игры — это та же граница, что и у исходного проекта. Оверлеи разведки и перевода только читают файлы журналов, которые пишет клиент. Перед использованием прочитайте Лицензионное соглашение с конечным пользователем EVE Online.

Приложение подключается к GitHub для проверки и загрузки обновлений. К ESI компании CCP и к сервису перевода оно подключается, только если вы включили эти необязательные функции, и отправляет только то, что описано в разделе [Конфиденциальность](#конфиденциальность).

EVE Online и связанные с ней логотипы являются товарными знаками CCP ehf. Этот проект не связан с CCP и не одобрен ею.

Значок приложения — мультяшная Смерть с косой, предоставленная сопровождающим проекта. `shared/branding/make-icons.py` строит из `shared/branding/logo-source.jpg` значки для macOS и Windows. Значок не содержит товарных знаков CCP и игровой графики.
