# EVE-O Preview for macOS

[English](README.md) | **简体中文** | [日本語](README.ja.md) | [한국어](README.ko.md) | [Русский](README.ru.md) | [Français](README.fr.md) | [Deutsch](README.de.md) | [Español](README.es.md)

EVE-O Preview for macOS 给每个运行中的 EVE Online 客户端显示一个实时缩略图。点击缩略图或按全局热键，即可切换到对应的客户端。

本项目按上游 [EveOPlus/eve-o-preview](https://github.com/EveOPlus/eve-o-preview)（Windows 版，GPL-3.0）的功能，用 Swift 在 macOS 上重新实现。我们没有移植上游的 C# 源码，界面与配置文件格式也与上游不同。
本项目以 GNU 通用公共许可证第 3 版或任何更新的版本（GPL-3.0-or-later）发布，与源码文件头的 SPDX 标识一致；上游以 GPL-3.0 发布。许可证全文见 [LICENSE](LICENSE)。

本仓库最初是 EveOPlus/eve-o-preview 在 GitHub 上的 fork，从 v1.0 起迁为独立仓库。本项目是独立项目，与 Windows 版没有共用代码，也不由上游作者维护。

## 功能

- 自动发现 EVE 客户端：客户端启动、退出、登录后改名时自动更新。
- 实时缩略图：每个客户端一条 ScreenCaptureKit 捕获流，尺寸与帧率可调。
- 缩略图面板：不抢焦点、出现在所有空间，可设置是否置顶。默认带 2 点浅灰边框，便于区分相邻的缩略图；颜色、粗细可调，也可以关掉。
- 切换：左键点缩略图切到对应客户端，Ctrl+点击最小化。右键菜单提供最小化、全部最小化、跳过循环、隐藏、恢复默认尺寸。
- 叠层：角色名标题、活动客户端的高亮边框（可按角色设颜色，打开时代替浅灰边框）、跳过循环的标记。
- 悬停放大（9 个锚点）与透明度。
- 可见性：隐藏活动客户端的缩略图；前台不是 EVE 时隐藏（带延迟）；按角色隐藏；全部隐藏。
- 布局：拖动移动、拖动缩放，吸附到其他缩略图与屏幕边缘，可锁定布局。每个角色分别保存位置与尺寸；登录界面的客户端使用单独的起始位置。
- 循环组：前进与后退热键、本次会话内跳过；每角色直达热键；登录客户端循环热键；全部隐藏与全部最小化热键。热键可以用鼠标中键与侧键，每条热键可设为全局生效或只在 EVE 内生效。
- 战斗提醒（默认关闭）：读取游戏日志，角色受到攻击时它的缩略图闪烁。
- 预警浮窗（默认关闭）：读取你指定的预警频道的聊天日志，按前台 EVE 窗口的角色显示敌对出现在哪个星系、离你几跳、有多少人、开什么船（见[预警浮窗](#预警浮窗)）。
- 聊天翻译浮窗（默认关闭）：把你指定的频道里其他语言的消息翻译成你的语言，用你选择的模型服务和你自己的 API Key（见[聊天翻译](#聊天翻译)）。
- 配置方案：新建、克隆、改名、删除、切换。
- 更新：检查 GitHub 上的新版本，核对下载文件与代码签名后在应用内安装（见[更新](#更新)）。
- 报告问题：生成脱敏的诊断 zip，并打开预填好的 GitHub Issue；应用意外退出后，下次启动时提示报告（见[报告问题](#报告问题)）。
- 菜单栏图标，代替 Windows 版的托盘图标。
- 设置窗口共 10 页：客户端、预览与布局、切换与热键、提醒、预警、翻译、配置方案、通用、权限、关于。
- 界面语言：英文（默认）、中文、俄文、日文、韩文、法文、德文、西班牙文，在「通用」页切换，也可以选「跟随系统」，切换后立即生效。俄、日、韩、法、德、西文的译文由机器生成，欢迎指正。

## 运行要求

- macOS 14 或更高版本，Apple Silicon 或 Intel 均可。发布的 dmg 内是通用二进制。
- EVE 客户端宜使用窗口模式。1.1.1 起支持原生全屏的客户端（打开「缩略图置顶」时缩略图显示在全屏画面上），但每个客户端在独立的空间里，切换时会有空间切换动画。

## 安装

### 下载发布版

1. 从 [Releases](https://github.com/deletexiumu/eve-o-preview/releases) 页面下载 `EVE-O-Preview-<版本号>.dmg`。
2. 打开 dmg，把 `EVE-O Preview.app` 拖进「应用程序」文件夹。
3. 打开应用。菜单栏出现图标，首次启动时自动打开设置窗口的「权限」页。

本项目没有 Apple 开发者 ID，发布版用本项目自己的自签名证书签名，没有经过公证。首次打开时，系统会拦截应用，提示无法验证开发者。按以下步骤打开：

1. 打开「系统设置 > 隐私与安全性」。
2. 向下滚动到关于 EVE-O Preview 的提示，点「仍要打开」，再确认。

如果系统提示应用「已损坏，无法打开」，或者不想走上面的步骤，可以在终端里去掉隔离属性：

```sh
xattr -dr com.apple.quarantine "/Applications/EVE-O Preview.app"
```

**注意：** 每个发布版都用同一张证书签名，升级后系统保留屏幕录制与辅助功能权限。如果升级后权限失效，用[权限](#权限)一节末尾的 `tccutil` 命令清除后重新授予。

应用会自行更新：定期检查 GitHub 上的新版本，并在应用内安装（见[更新](#更新)）。

每个发布版还附带 `.tar.gz` 与 `.zip` 两种源码包和 `SHA256SUMS.txt`。要核对下载的文件，在下载目录里运行 `shasum -a 256 --ignore-missing -c SHA256SUMS.txt`。

### 从源码构建

想自己构建应用，请看 [docs/macos/development.md](docs/macos/development.md)（英文），其中也介绍了调试工具、CI 和发布流程。

## 权限

应用用到以下系统权限，都在「系统设置 > 隐私与安全性」里授予。设置窗口的「权限」页显示它们的状态，并提供请求按钮与系统设置的跳转。

| 权限 | 用途 | 缺少时 |
| --- | --- | --- |
| 屏幕录制 | 捕获客户端画面，读取窗口标题 | 缩略图显示占位画面；没有辅助功能权限时，标题也读不到，客户端显示为 `EVE (PID)` |
| 辅助功能 | 还原、提升、最小化客户端窗口，读取窗口标题，拦截鼠标热键 | 只能激活客户端进程，已最小化的窗口还原不了；「最小化」与「全部最小化」菜单项置灰；鼠标热键不生效，键盘热键照常 |
| 文稿文件夹 | 战斗提醒读取 `~/Documents/EVE/logs/Gamelogs`；预警浮窗与翻译浮窗读取 `~/Documents/EVE/logs/Chatlogs`，预警浮窗还读游戏日志来确定你的位置 | 只在打开其中一项功能，或在「从日志添加」菜单里点「刷新」时请求；拒绝后该功能的设置页显示原因，其他功能不受影响 |
| 本地网络（macOS 15 起） | 连接局域网里另一台电脑上的翻译服务，如 Ollama | 只在翻译服务位于局域网里的另一台电脑时请求，本机与公网服务不请求；可以先在「翻译」页点「测试」，让这个提示先出现。拒绝后，发往那台电脑的请求以网络错误失败。「权限」页不显示这一项 |

授予屏幕录制权限后，通常要重新启动应用才生效，「权限」页有「重新启动」按钮。辅助功能权限授予后立即生效。

如果授权记录错乱，运行以下两条命令，再重新授权：

```sh
tccutil reset ScreenCapture io.github.deletexiumu.eveopreview-macos
tccutil reset Accessibility io.github.deletexiumu.eveopreview-macos
```

## 使用

### 缩略图手势

左键按下立即切换，不等松开，所以移动与缩放用右键拖动或 Option+左键拖动。

| 操作 | 手势 |
| --- | --- |
| 切换到该客户端 | 左键按下 |
| 最小化该客户端 | Ctrl+左键按下 |
| 打开菜单 | 右键单击（按下到松开之间移动不到 4 点） |
| 移动 | 右键拖动，或 Option+左键拖动 |
| 缩放 | 同移动的手势，从缩略图边缘 12 点以内开始拖动 |
| 临时不吸附 | 拖动时按住 Shift；缩放时按住 Shift 同时保持宽高比 |

打开「锁定布局」后，移动与缩放不起作用，切换、最小化与菜单照常。

### 热键

热键在设置窗口的「切换与热键」页录制：点按钮后按下组合键或鼠标按键，Esc 取消，Delete 清除。一个动作可以绑定多个组合。

- 循环组：每组有前进与后退热键，在组内在线、未被跳过的角色之间按顺序切换，到末尾后回到开头。
- 角色直达热键：切到指定角色的客户端。
- 通用热键：显示或隐藏全部缩略图、全部最小化、在登录界面的客户端之间循环。

键盘热键应包含 Ctrl、Option、Command 之一；F1～F20 与小键盘数字可以单独使用。Cmd+Tab、Cmd+Space、Cmd+Q 等系统组合会被拒绝。热键有问题时，设置窗口在它旁边显示原因。

鼠标热键：

- 可以录制中键与侧键（配置里写作 `Mouse3`～`Mouse32`），可以带修饰键，如 `ctrl+Mouse4`。左键与右键不能绑定。
- 热键触发时，这次点击（按下、拖动、松开）不会传给前台应用，游戏里绑在同一个按键上的动作不会执行。
- 需要辅助功能权限。

作用范围：

- 每条热键可设为「全局」或「仅 EVE 内」，配置里写作后缀 `@global`、`@game`。没有后缀的热键跟随配置方案的默认作用范围。
- 「仅 EVE 内」的热键只在 EVE 客户端位于前台时生效，在其他应用里按下时照常传给那个应用。
- 新录制的鼠标热键默认只在 EVE 内生效，避免在所有应用里拦截侧键。
- 菜单栏菜单的「热键只在 EVE 内生效」可一键切换默认作用范围。

### 战斗提醒

在设置窗口的「提醒」页打开。打开后应用读取 `~/Documents/EVE/logs/Gamelogs` 里客户端新写入的游戏日志，按日志文件头的收听者把日志对应到角色；某个角色受到攻击时，它的缩略图边框与画面闪烁 3 秒。

- EVE 客户端要开启游戏日志记录（默认开启）。
- 被打空（未命中）默认也提醒，可以关掉；可设最小伤害值、闪烁颜色与时长。
- 打开「离开 EVE 时隐藏」时，受到攻击的角色的缩略图会临时显示。
- 系统设置里打开「减弱动态效果」时，闪烁改为常亮。
- 应用只读日志，不写入、不修改，也不向游戏发送输入。
- 第一次打开时，系统会询问是否允许访问「文稿」文件夹。日志在其他位置时，可以在「提醒」页选择目录。
- 中文客户端的日志格式已用真实日志核对。日文、俄文伤害行已用真实客户端日志核对（上游的录制样例），未命中只按模板推出。英、德、法、西、韩文按上游的模板推出，尚未用真实日志核对。

### 预警浮窗

在设置窗口的「预警」页打开「显示预警浮窗」，或者在菜单栏菜单里点「显示预警浮窗」。打开后应用读取客户端写入 `~/Documents/EVE/logs/Chatlogs` 的聊天日志，这个目录与「提醒」页选的游戏日志目录同级。浮窗里每行是预警频道的一条消息：多久以前、每个星系及其安全等级与离你几跳、敌对人数、舰船和人名。

- EVE 客户端应开启把聊天记录写入文件的设置。
- 客户端语言不是英文时，Mac 版 EVE 可能不写本地、军团、联盟的聊天日志（中文客户端已确认），两个浮窗里这些频道就一直是空的。把 EVE 的语言改为 English 后重新登录角色即可；出现这种情况时，翻译浮窗的状态行会提示。
- 频道：点「从日志添加」，从最近的聊天日志里出现过的频道中选（每项显示你有几个角色在这个频道里）；也可以在输入框里输入频道名后按回车。只在功能打开时，或在「从日志添加」菜单里点「刷新」时读取日志目录；功能关着时，菜单里起初只有「刷新」（「翻译」页另有内置频道）。最多 16 个频道。私聊频道不读取，也不出现在列表里。
- 打开后，浮窗先补上最近 30 分钟的消息（「保留最近」，5～120 分钟），更早的行自动消失。
- 位置：跳数从活动角色所在的星系算起。应用从游戏日志里的跳跃与离站记录、`Local` 聊天日志里的星系切换消息取得位置。两者都没有时，在「我的位置」里给这个角色输入星系名后按回车；名称查不到时显示「找不到这个星系」。手动位置在重启后保留，角色下次跳跃后被新位置覆盖。完全没有位置的角色从「参考星系」算跳数。
- 「最多计算」限定跳数的上限（1～30，默认 15）。报告的星系在「高亮距离」以内时，这一行高亮（默认 5，设为 0 时不高亮）。「显示原文」在第二行列出说话人与原文。
- 星系与舰船名按界面语言显示。
- 人名是消息里认出星系、舰船和人数后剩下的部分，所以几个带空格的人名连在一起时分不清。打开「联网核对人名（ESI）」时（默认打开），应用向 CCP 的 ESI 查出这些词里哪些是真实的角色名，再按查到的结果分人（见[隐私](#隐私)）。查到只说明有角色叫这个名字，不保证消息里说的就是这个角色。查到的人名在右键菜单的「在浏览器中打开」里有 zKillboard 的链接。「清空人名缓存」删除已保存的人名。

### 聊天翻译

在「翻译」页打开「显示翻译浮窗」，或者在菜单栏菜单里点「显示翻译浮窗」。它翻译所选频道里不是目标语言的消息。

1. 按预警浮窗的方法选频道；「从日志添加」另外列出内置的本地、军团、联盟、舰队频道。
2. 在「翻译成」里选一种语言，或「跟随界面语言」（默认）。
3. 选「服务」：DeepSeek（默认）、Claude (Anthropic)、OpenAI、Qwen (DashScope)、Kimi (Moonshot)、Ollama，或「其他（OpenAI 兼容接口）」。「接口地址」与「模型名」显示预设的值，填写后覆盖预设。
4. 粘贴 API Key 后点「保存」。Key 存进 macOS 钥匙串，「删除 Key」删除它。Ollama 不用 Key。
5. 点「测试」翻译一句固定的样例。

- 只有活动客户端的角色收到的消息才发给模型。相同的句子只翻译一次，之后从缓存里取。只有星系、舰船的消息不发送。目标语言是中文、日文、韩文或俄文时，已经是这种语言的消息也不发送。目标语言是英文、德文、法文或西班牙文时，这些消息都发给模型，由模型判断是否已是目标语言。星系、星域与舰船名使用目标语言的官方名称。
- 每行显示 EVE 时间、频道（翻译的频道多于一个时）、说话人与译文。「同时显示原文」在下面列出原文；「只显示翻译过的消息」隐藏因已是目标语言而跳过的消息，也隐藏模型判断为目标语言的消息。
- 服务拒绝 Key 或额度用完时，翻译暂停，状态行显示原因；点「立即重试」再试一次。
- 公网地址只能用 `https`；`http` 只能用于本机或局域网，如 Ollama 的 `http://127.0.0.1:11434/v1`。
- 请求使用你在所选服务上的账户，可能产生费用。
- 重新构建后签名变了时，点「测试」或「立即重试」，系统可能请你允许读取钥匙串里的这一项。按设计，后台的读取不弹出这个窗口，只在状态行提示你重新保存 Key；这一点还待在真实的重新构建后手工核实。

### 浮窗手势

预警浮窗与翻译浮窗是两个独立的面板，行为与缩略图相同：不抢焦点、出现在所有空间，只显示前台 EVE 窗口的角色，切换客户端时立即换内容。点击不会穿透到游戏。最新的消息在最下面，列表停在底部。向上滚动后，列表不再跟随新消息，底部出现「N 条新消息」；点它回到最新。

| 操作 | 手势 |
| --- | --- |
| 滚动列表 | 滚轮或触控板双指滑动 |
| 移动 | 右键拖动，或 Option+左键拖动 |
| 缩放 | 同移动的手势，从浮窗边缘 12 点以内开始拖动 |
| 临时不吸附 | 拖动时按住 Shift |
| 打开菜单 | 右键单击（按下到松开之间移动不到 4 点） |
| 回到最新 | 点「N 条新消息」 |

右键菜单提供：滚动到最新、复制这一条、在浏览器中打开（只在带链接的行上出现）、清空列表、锁定布局、恢复默认位置与尺寸、隐藏此浮窗、打开设置…。「背景不透明度」（20%～100%，只改背景，文字始终不透明）与「字号」（10～24 点）在各功能的设置页里。「锁定布局」与「离开 EVE 时隐藏」对浮窗同样生效；「全部隐藏」只管缩略图。

### 菜单栏

菜单栏图标与应用图标同为八边形框里的分子图案。菜单提供：显示或隐藏全部缩略图、切换配置方案、全部最小化、热键只在 EVE 内生效、显示预警浮窗、显示翻译浮窗、检查更新…、报告问题…、设置、退出。有可用的更新或上次运行意外退出时，图标上出现一个圆点，菜单顶部多出对应的一项。缺少权限时多一项权限提示。如果你在系统的录制指示器里停止了某个客户端的捕获，菜单里会多一项「恢复捕获」。

应用同时在 Dock 里显示图标，点它打开设置窗口。只想保留菜单栏图标时，在「设置 > 通用」里关掉「在 Dock 中显示图标」。

### 更新

应用在启动时和每天检查一次 GitHub 上的新版本。要关掉自动检查，在「设置 > 通用 > 更新」里关掉「自动检查更新」；菜单栏菜单的「检查更新…」仍可随时手动检查。

有新版本时，窗口按界面语言显示发布说明（没有对应译文时显示英文），提供「安装更新」「跳过此版本」「稍后」。EVE 客户端在前台时，窗口等你切走后才出现，也不会自己抢键盘焦点；菜单栏图标上的圆点表示有更新在等待。「跳过此版本」只停止该版本的自动提醒，「检查更新…」仍会显示它。

「安装更新」下载 dmg，按 `SHA256SUMS.txt` 核对，确认新应用与正在运行的应用用同一张证书签名，然后替换应用并重新启动。任何一步失败，已安装的应用都保持不变。「自动安装更新」默认打开：更新在后台下载；没有 EVE 客户端运行满约 1 分钟、也没有打开 EVE-O Preview 的窗口时，自动安装并重新启动。否则等你退出应用，或在菜单栏菜单里点「重新启动以更新到 X.Y.Z」时安装。有 EVE 客户端在运行时，应用不会自己重新启动。想先由窗口询问，在「设置 > 通用 > 更新」里关掉它。

以下构建只显示原因和「打开发布页」按钮，不能在应用内安装：ad-hoc 或本机证书签名的构建、从磁盘映像或被系统转移到随机位置运行的应用、所在文件夹没有写权限的应用、装在非 APFS 卷上的应用（如 HFS+、exFAT 或 FAT 格式的外置磁盘）。

### 报告问题

在菜单栏菜单或「通用」页选「报告问题…」，或者在应用意外退出后的提示里选择报告。窗口列出报告里的每个文件，并显示脱敏后的内容：环境摘要、不含名字的配置摘要、应用日志（最多 2 MiB）和最多 3 份 macOS 崩溃报告。点「只生成报告」或「生成报告并打开 GitHub」之前，不会生成任何文件。zip 存到 `~/Library/Application Support/EVE-O Preview/Reports/`（保留最新的 3 个），并在访达中显示；「生成报告并打开 GitHub」还会在浏览器里打开预填好的 Issue。zip 由你自己拖进 Issue，应用不上传任何文件。

macOS 用户名、全名、主目录路径与电脑名替换为 `[user]` 与 `[host]`。EVE 角色名替换为 `[character-1]`、`[character-2]` 等，崩溃报告里的设备标识替换为 `[redacted]`。只替换应用知道的名字：没在配置里出现过、也没作为运行中的客户端出现过的角色名不会被替换。如果某个名字是常用词，日志里其他地方的同一个词也会被替换。生成报告前可以阅读每个文件，取消勾选不想附上的文件。

应用在 `~/Library/Logs/EVE-O Preview/` 下最多保留 5 个日志文件，每个 1 MiB。角色名与窗口标题记为 `<private>`。在「通用」页打开「详细日志」可记录调试信息，「在访达中显示日志」打开日志文件夹。如果崩溃后没有出现提示，可以手动把 `~/Library/Logs/DiagnosticReports/EVEOPreview-<日期>.ips` 附到 Issue 里。

## 隐私

应用为了更新访问 GitHub；除非你打开列表之后说明的可选功能，否则不发其他网络请求：

- 检查更新：「自动检查更新」打开时，在启动后与每天请求一次 `api.github.com/repos/deletexiumu/eve-o-preview/releases/latest`；你点「检查更新…」时也请求一次。
- 有新版本要提示时，再请求一次 Release 列表 `api.github.com/repos/deletexiumu/eve-o-preview/releases`（请求头相同），用来显示你跳过的中间版本的更新内容。
- 安装更新：从 Release 下载 `SHA256SUMS.txt` 与 dmg。

请求里只有 `User-Agent` 请求头里的应用版本号、固定的 `Accept-Language: en` 和一个缓存标签；不发送角色名、配置、日志、硬件信息、系统版本或任何标识符，不用 cookie。GitHub 能看到的是你的 IP 地址和请求时间。应用没有遥测，也不自动上传崩溃信息：「报告问题…」只在本机生成 zip，并打开一个网页，提交与否由你决定。

预警浮窗与翻译浮窗只读聊天日志和游戏日志，不写入；私聊频道不读取。以下两项可选功能会访问其他服务：

- 人名核对：打开预警浮窗后，「联网核对人名（ESI）」默认打开。活动角色收到的情报消息里有两个词以上的人名连在一起时，应用把这些词（单个词，以及至多 3 个词的组合）发给 CCP 的 ESI 接口 `esi.evetech.net/universe/ids`。不发送说话人、频道名与消息的其余部分；你自己的角色名只在别人把它写进情报时才会在其中。单独成段、只有一个词的人名不查。CCP 能看到你的 IP 地址和 `User-Agent` 请求头，里面是应用版本与项目地址。在「预警」页关掉这个开关后不再发这些请求。应用自己不访问 zKillboard：「在浏览器中打开」在浏览器里打开角色的 zKillboard 页面，地址里只有角色 ID。
- 聊天翻译（默认关闭）：活动客户端的角色在翻译频道里收到的消息正文，连同其中星系与舰船的官方名称，发给你在「翻译」页选择的模型服务。不发送说话人与频道名；「测试」只发一句固定的样例。API Key 只存在 macOS 钥匙串里，服务名是 `io.github.deletexiumu.eveopreview-macos.translation`，每个服务一项，只发给这个服务；它不写进配置文件、日志与问题报告。公网地址只能用 `https`，`http` 只能用于本机或局域网（如 Ollama）。服务如何处理这些文字，以它自己的条款为准。

问题报告里有这两项功能的设置，只是数字与开关（如频道个数、选的服务），没有频道名、星系名、接口地址、模型名、人名、聊天原文与 Key。

应用在以下位置存放数据。要完全卸载，删除应用时一并删除它们和 `~/Library/Application Support/EVE-O Preview/config.json`：

| 位置 | 内容 |
| --- | --- |
| `~/Library/Logs/EVE-O Preview/` | 应用日志，最多约 5 MiB |
| `~/Library/Application Support/EVE-O Preview/session.json`、`state.json` | 会话标记；更新与诊断的记录；预警的手动位置 |
| `~/Library/Application Support/EVE-O Preview/Reports/` | 你生成的问题报告 zip，已脱敏（保留最新的 3 个） |
| `~/Library/Caches/io.github.deletexiumu.eveopreview-macos/Updates/` | 下载的更新文件，安装后删除 |
| `~/Library/Application Support/EVE-O Preview/pilot-names.json` | ESI 查到的人名与角色 ID（游戏的公开数据），保留 30 天。只有你能读写（0600），不进问题报告；「预警」页的「清空人名缓存」清空它。没查到的名字只在内存里留 6 小时 |
| `~/Library/Application Support/EVE-O Preview/translation-cache.json` | 聊天原文与译文，没有说话人与频道名。只有你能读写（0600），不进问题报告；「翻译」页的「清空缓存」清空它 |
| 钥匙串里服务名为 `io.github.deletexiumu.eveopreview-macos.translation` 的项 | 翻译用的 API Key，每个服务一项；「翻译」页的「删除 Key」删除当前服务的一项 |

## 配置文件

配置保存在 `~/Library/Application Support/EVE-O Preview/config.json`。一个文件装下全部配置方案。

- 设置改动后 0.5 秒自动保存，退出时再保存一次。
- 文件损坏时，原文件被改名为 `config.corrupt-<日期时间>.json`，应用使用默认配置。
- 文件来自更新的版本时，应用使用默认配置运行，本次会话不写盘，不覆盖原文件。

「配置方案」页有「在访达中显示」按钮。

## 未移植的上游功能

| 上游功能 | 原因 |
| --- | --- |
| 帧率限制、选择性静音（Robin 注入） | 上游向 Windows 进程注入 DLL 实现，macOS 没有对应的公开机制 |
| CPU 亲和性 | 依赖 Windows CPU Sets；Apple Silicon 没有按进程指定核心的公开接口 |
| 战斗日志增强（Augments）中的伤害数字、DPS、维修量、星系叠层，FC 静态数据 | 独立的大型子系统，不属于「预览与切换」；只移植了「受到攻击时闪烁」 |
| 主题、Legacy 界面、自定义右键菜单样式 | macOS 版跟随系统外观 |
| 兼容捕获模式（`PrintWindow`） | ScreenCaptureKit 是唯一的捕获方式 |
| 低级键盘钩子 | 键盘热键用 Carbon 全局热键；只有绑定了鼠标按键时才建立鼠标事件监听 |

区域（Regions）与拖放停靠、多选与成组移动、撤销、吸附参考线、导入 Windows 版配置、登录时启动，计划在 v1 之后再做。
