EVE-O Preview for Windows
=========================

Live thumbnails and fast switching for multiple EVE Online clients.

Getting started
- Unzip this folder anywhere you can write to (for example Documents or D:\Games).
  Avoid "Program Files": automatic updates need to replace the exe in place.
- Run "EVE-O Preview.exe". The icon appears in the notification area (near the clock).
  Left-click it to open Settings; right-click it for the menu.
- Windows may show "Windows protected your PC" the first time, because the exe is
  not code-signed yet. Click "More info", then "Run anyway".

Updates
- EVE-O Preview checks GitHub for new versions and can install them automatically.
  Each update package is verified with a signature before it is installed.
  You can turn this off under Settings > General.

Your data
- Settings:  %APPDATA%\EVE-O Preview\
- Logs:      %LOCALAPPDATA%\EVE-O Preview\logs\
- To remove EVE-O Preview, quit it from the tray menu, turn off "Start when I sign
  in to Windows" if you turned it on, then delete this folder and the two folders above.

EVE-O Preview（Windows 版）

为多开的 EVE Online 客户端提供实时缩略图与快速切换。

开始使用
- 把这个文件夹解压到你有写权限的位置（例如「文档」或 D:\Games）。
  不要放在「Program Files」下：自动更新需要原地替换 exe。
- 运行「EVE-O Preview.exe」。图标出现在通知区域（时钟旁边）。左键打开设置，右键打开菜单。
- 第一次运行时 Windows 可能提示「Windows 已保护你的电脑」，因为 exe 还没有代码签名。
  点「更多信息」，再点「仍要运行」。

更新
- 应用会到 GitHub 检查新版本，并可以自动安装。每个更新包都先核对签名再安装。
  可以在「设置 > 通用」里关闭。

你的数据
- 设置：%APPDATA%\EVE-O Preview\
- 日志：%LOCALAPPDATA%\EVE-O Preview\logs\
- 卸载：从托盘菜单退出；如果打开过「登录 Windows 时启动」，先关掉它；然后删除这个文件夹和上面两个文件夹。
